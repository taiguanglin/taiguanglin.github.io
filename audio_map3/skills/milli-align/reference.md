## A. golden 實測數字（楞伽 L1–4）

### A.1 鏈（chaining）
- 逐字頭命中的 READ 段：`golden.start − prev_READ.end` median **+0.000**、mean +0.000
  ——UI 的邊界同步把 end[i-1]=start[i] 變成建構事實。
- 299 對相鄰 READ 中僅 14 個破口（L2 0.33s 縫、−2.37s 重疊、0.36s 縫；L4 +0.57/+1.17/

  ——人工偶爾接受縫/重疊（<5%），自動化一律用鏈（停頓歸下一段 lead-in）。

### A.2 段首 lead-in（19 個逐字頭 READ 段）
- `golden.start − t(第一個逐字內容字)`：median **−0.843**，p25 −1.621，p10 −2.898，
  **max 0.00（絕不晚於內容字）**。
- 意義：師父段首常有引導語（「那么」「我们看」、語氣詞、呼吸），golden 把這段 run
  全部算進本段。start = run-onset，不是 t(內容字)−0.15。
- run-onset 判定：從內容字往回走，停頓 ≥0.7s 處或 prev_end 處停（兩者取大）。
  實測 TH=0.7 時 19/19 誤差 ≤0.3s；TH≤0.6 會誤切師父的自然句間停頓。

## B. 講首長 passage 的結構（楞伽 L5 實錄）

L5 開頭 [3]–[13] 是同一長 passage 的印刷參考塊，音檔實際流程（105–154s）：

```
書序：[3]全passage塊 → [14]短引文 → [15]講解 → [16]續段引文 → [17]講解 → [18]重引 → …
語序：念第一句(107–111) → 插講[15]內容(112–121) → 續念整段(122–154) → 逐行重引+講解(155+)
```

正確產出（書序≠語序的標準解法）：
- `[3]`（全 passage 印刷塊）＝ **zero**——朗讀被書序在後的 `[14]`、`[16]` 認領；
- `[14]`（第一句短引文）＝ READ `[107.4, 112.3]`；
- `[15]`（插講）＝ READ `[112.3, 121.7]`——**中斷插講**：講解嵌在朗讀中間；
- `[16]`（續段引文）＝ READ `[121.7, 154.3]`（剩餘全文續念，語速 ~4.3 字/s 自洽）；
- `[18]`、`[20]`＝後方講解前的**部分重引**（「如來世尊于观自在」只有頭 8 字）→ READ 短 span，
  各自只蓋實際念出的那截；`[22]`、`[24]`、`[27]`、`[29]` 同理拿第二次 vocalization。
- 教訓：上一版管線把 `[14]` 給了整個 49s（胖 span）、把 `[16]/[18]/[20]` 全 zero——
  兩個錯都是「書序≠語序 + 重引歸屬」沒處理好。

### B.1 行內引文歸屬實例
- `[50]`「时虚空中梵释四天」：獨立重引、匹配比 `[51]` 行內的「梵释四天」更完整 → 歸 `[50]` READ。

## E. 工具與陷阱

- `dump_window.py` 的 dump 路徑 glob（`*{N}.json`）會把 `15.json` 排在 `5.json` 前——
  判讀時直接餵 `/tmp/funasr_cache/<series>/<N>.json` 給 `load_dump`。
- ASR 同音錯字對照：凡诗四天=梵釋四天、大观行诗=大观行师、便于制作=遍一切处、
  保证真实=证真实、等于二乘三位过失=远离二乘三昧过失、茅伦助飞静=毛轮住非净智境、
  操作硬化所做所应做事=超诸应化所应作事、古今炼的充电如来大神动力=我今愿得重见如来大神通力、
  持续控制中=时虚空中（楞伽 L5 [50]）、休(息)=修(習)、任亲王=楞伽王、旷法理非凡=况法与非法。
- `FILLER_RE` 只列單字語氣詞（啊呀吧嗯呃哦啦哇欸诶喽嘍嘛咧咯哟），lead-in 的實詞
  （那么/我们看/后边呢）不在其中——run-onset 走「停頓」而不是「詞性」。
- `norm_para()` 會 t2s＋去標點＋去語氣詞——逐字掃描前先 normalize，並記得 ASR 的
  「嗯」等擬聲不在 FILLER_RE。
