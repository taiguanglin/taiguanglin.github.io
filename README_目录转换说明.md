# 问答录目录转Word文档工具

## 功能说明

这个工具可以将问答录的文本目录文件（如 `wenda2-toc-2025-08-18v2.txt`）转换为格式化的Word文档目录。

## 文件说明

- `wenda2_toc_to_word.py` - 主要转换程序
- `requirements.txt` - Python依赖包列表
- `new_toc/wenda2-toc-2025-08-18v2.txt` - 输入的目录文件
- `问答录目录.docx` - 输出的Word文档

## 安装依赖

```bash
pip install python-docx
```

或者：

```bash
pip install -r requirements.txt
```

## 使用方法

### 基本使用

```bash
python3 wenda2_toc_to_word.py
```

程序会自动：
1. 读取 `new_toc/wenda2-toc-2025-08-18v2.txt` 文件
2. 解析目录结构和层级
3. 生成格式化的Word文档 `问答录目录.docx`

### 转换结果

生成的Word文档包含：

#### 层级格式
- **一级标题** (I., II., III.): 16pt 微软雅黑，加粗
- **二级标题** (I.I., I.II.): 14pt 微软雅黑，加粗
- **三级标题**: 12pt 宋体
- **四级标题**: 11pt 宋体
- **更深层级**: 10pt 宋体

#### 缩进设置
- 一级标题：无缩进
- 二级标题：0.8cm 缩进
- 三级标题：1.6cm 缩进
- 四级标题：2.4cm 缩进
- 更深层级：递增缩进

#### 條目數顯示
- 主要章节：右侧显示 (數字條) 格式
- 子章节：右侧显示 (數字條) 格式
- **重要說明**: 括號內數字代表該分類包含的條目數量，不是頁碼

- **处理时间**: 实时显示进度

## 文档结构

转换后的Word文档包含两部分：
1. **主目录**: 格式化的分层目录结构
2. **统计信息**: 转换统计和生成时间

## 技术特性

### 智能层级识别
- 自动识别罗马数字标题 (I., II., III.)
- 基于箭头符号 (->) 判断层级深度
- 根据缩进空格计算相对层级

### 格式优化
- 中文字体优化 (微软雅黑 + 宋体)
- 合理的行间距和段落间距
- 层级化的缩进和字体大小

### 错误处理
- 文件不存在检查
- 编码问题处理
- 转换过程异常捕获

## 自定义修改

如需修改输出格式，可以调整 `add_toc_entry` 方法中的：
- 字体类型和大小
- 缩进距离
- 行间距设置
- 页码格式

## 注意事项

1. 确保输入文件使用UTF-8编码
2. 目录文件应保持原有的缩进和格式
3. 條目數信息應在行末用括号 (数字) 格式标注
4. 运行前确保有足够的磁盘空间存储输出文件

## 系统要求

- Python 3.6+
- python-docx 库
- 支持中文字体的系统环境
