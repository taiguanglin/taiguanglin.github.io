# TOC 生成器技術說明

## 🏗️ 架構概述

這個工具採用**雙層架構**設計：
- **服務端（Python）**：文件解析和 HTML 生成
- **客戶端（JavaScript）**：動態匯入和目錄重建

## 🔧 核心技術

### 1. 智能解析引擎

#### Python 端解析器
```python
# 羅馬數字模式 - 修復了 IV 識別問題，將較長模式放在前面
ROMAN_PATTERN = re.compile(r'^((?:XI{0,3}|IX|VI{0,3}|IV|I{1,3}|X|V)(?:\.(?:XI{0,3}|IX|VI{0,3}|IV|I{1,3}|X|V))*)\.?\s*(.+)$')

# 阿拉伯數字模式  
ARABIC_PATTERN = re.compile(r'^(\d+(?:\.\d+)*)\.?\s+(.+)$')

# 舊結構模式
OLD_STRUCTURE_PATTERN = re.compile(r'.*->.*')
```

#### 重要修復說明
- **問題**：原始正則表達式 `I{1,3}|IV` 會導致 `IV` 被錯誤地匹配為 `I`，因為 `I{1,3}` 先匹配了 `IV` 中的第一個 `I`
- **解決方案**：重新排序模式，將較長的模式（如 `XI{0,3}`, `IX`, `VI{0,3}`, `IV`）放在較短的模式（如 `I{1,3}`, `X`, `V`）之前
- **結果**：正確識別 `IV.【生活】` 等羅馬數字項目

#### JavaScript 端解析器
```javascript
class ClientTOCParser {
  constructor() {
    this.romanPattern = /^((?:I{1,3}|IV|V|VI{0,3}|IX|X|XI{0,3})(?:\.(?:I{1,3}|IV|V|VI{0,3}|IX|X|XI{0,3}))*)\.?\s+(.+)$/;
    this.arabicPattern = /^(\d+(?:\.\d+)*)\.?\s+(.+)$/;
    this.oldStructurePattern = /.*->.*/;
  }
}
```

### 2. 層次結構構建

#### 羅馬數字主導的層次結構
```python
def _build_hierarchy(self) -> List[TocItem]:
    root_items = []
    stack = []  # 只追蹤羅馬數字父項目
    
    for item in self.items:
        if item.is_roman:
            # 只有羅馬數字項目參與層次結構構建
            while stack and stack[-1].level >= item.level:
                stack.pop()
            
            if stack:
                stack[-1].children.append(item)
            else:
                root_items.append(item)
            
            stack.append(item)
        else:
            # 所有非羅馬數字項目都作為內容添加到最近的羅馬數字項目下
            if stack:
                stack[-1].children.append(item)
            else:
                root_items.append(item)
```

#### 層次結構規則
1. **結構項目**：只有羅馬數字項目（`I.`, `I.I`, `I.I.I` 等）參與層次結構構建
2. **內容項目**：阿拉伯數字項目、舊結構項目、非數字項目都作為內容附加到最近的羅馬數字項目下
3. **層級關係**：羅馬數字項目根據其層級（點號數量）確定父子關係

## 🎨 樣式系統

### CSS 類別結構
```css
.has-children        /* 有子項目的節點 */
.arabic-numeric      /* 阿拉伯數字結構 */
.old-structure       /* 舊結構（包含箭頭） */
.non-roman           /* 非羅馬數字結構 */
.number-badge        /* 數字徽章樣式 */
```

### 結構分類邏輯
```javascript
// 檢查羅馬數字模式
const isRoman = labelText.match(romanPattern);

// 檢查阿拉伯數字模式  
const isArabic = labelText.match(arabicPattern);

// 檢查舊結構（包含箭頭）
const isOldStructure = labelText.match(/.*->.*/);

// 應用對應的 CSS 類
if (isOldStructure) {
  li.classList.add('old-structure');
}
if (isArabic && !isOldStructure) {
  li.classList.add('arabic-numeric');
} else if (!isRoman && !isArabic) {
  li.classList.add('non-roman');
}
```

### 視覺區分
- **羅馬數字**：默認樣式
- **阿拉伯數字**：綠色字體 (`color: #059669`)
- **數字徽章**：藍色背景 (`background: rgba(59, 130, 246, 0.1)`)

### "只顯示數字目錄" 功能
```css
/* 隱藏舊結構和非數字項目，保留羅馬數字和阿拉伯數字 */
.hide-old-structure .old-structure,
.hide-old-structure .non-roman:not(.arabic-numeric) {
  display: none;
}
```

此功能會：
- ✅ **保留顯示**：羅馬數字結構 + 阿拉伯數字結構
- ❌ **隱藏**：舊結構（箭頭結構）+ 非數字結構
