🧹 符号过滤测试验证

问题分析

用户发现匯出时包含了 ⏬ 符号，这是展开按钮的图标。

问题影响：导致匯出的文本包含不必要的UI控制符号，影响文件的可读性和重用性。

修复前后对比

修复前 ❌

I. 真相、意识、羯磨（业） (471) ⏬
  I.I. 自性与真相 (74) ⏬
    1 自性与意识 -> 1.2.4 自性遍虚空 (6) 📋

包含UI控制符号，影响匯出质量

修复后 ✅

I. 真相、意识、羯磨（业） (471)
  I.I. 自性与真相 (74)
    1 自性与意识 -> 1.2.4 自性遍虚空 (6)

干净的文本，无多余符号

技术修改详情

修改的代码：

// 修改前
text = text.replace(/📋/g, '').trim();

// 修改后
text = text.replace(/[📋⏬🔽🔼⏫📁📄]/g, '').trim();

过滤的符号：

  • 📋 - 复制按钮
  • ⏬ - 展开子项按钮
  • 🔽🔼⏫ - 展开/收起按钮（预防性过滤）
  • 📁📄 - 匯入/匯出按钮（预防性过滤）

测试步骤

  1. 打开 index.html
  2. 展开一些有子项的节点（应该看到 ⏬ 按钮）
  3. 点击 "📄 汇出" 按钮
  4. 检查下载的文件是否不再包含 ⏬ 等UI符号
  5. 验证所有括号数字仍然正确保留

预期结果

✅ 匯出文件应该完全没有UI控制符号

✅ 所有节点的括号数字应该保留

✅ 层次缩进应该正确

✅ 文件应该可以重新匯入
