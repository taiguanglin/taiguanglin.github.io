# TOC 目錄生成工具使用說明

這個工具可以從 `toc_full.txt` 格式的文件生成可折疊的 HTML 目錄頁面，並支持瀏覽器端的匯入/匯出功能。

## 🚀 快速開始

### 1. 生成 HTML 目錄
```bash
python toc_generator.py toc_full.txt
```

### 2. 指定輸出目錄
```bash
python toc_generator.py toc_full.txt -o 輸出目錄
```

### 3. 自定義 HTML 文件名
```bash
python toc_generator.py toc_full.txt -o 輸出目錄 --html-name 自定義名稱.html
```

## 📁 文件說明

- **`toc_generator.py`** - 主程式文件
- **`toc_full.txt`** - 示例 TOC 文件（羅馬數字格式）
- **`index.html`** - 生成的示例 HTML 頁面
- **`toc-style.css`** - 樣式文件
- **`toc-script.js`** - 交互功能腳本

## 🔧 支持的文件格式

### 羅馬數字格式
```
I. 【义理】说明：坐禅1坐禅2关于义理部分细问的 (1834)
  I.I 真相 (74)
    I.I.I 自性恒常 (54)
      I.I.I.I 自性遍虚空 (6)
        1 自性与意识 -> 1.2 初妄无因 -> 1.2.4 自性遍虚空与妄想的局限 (6)
      I.I.I.II 自性不生不灭 (7)
II. 【修心】说明：修行法门打坐磕头等问题 (2632)
  II.I 修行要领 (266)
```

### 阿拉伯數字格式
```
1. 第一章：基礎概念 (50)
  1.1 基本定義 (15)
    1.1.1 核心概念 (8)
    1.1.2 相關術語 (7)
  1.2 理論基礎 (20)
    1.2.1 歷史發展 (10)
    1.2.2 現代觀點 (10)
2. 第二章：進階內容 (75)
  2.1 深入探討 (30)
```

## 🎯 主要功能

### 📊 智能解析
- **羅馬數字結構**：`I.`, `I.I`, `I.I.I` 等
- **阿拉伯數字結構**：`1.`, `1.1`, `1.2.3` 等
- **舊結構標記**：包含 `->` 的項目
- **忽略縮排**：完全基於數字模式判斷層次

### 🌳 可折疊樹狀結構
- 多層級展開/收起
- 點擊任意項目切換狀態
- 鍵盤支持（Enter/Space）

### 🎛️ 控制功能
- **第 1-5 層**：快速展開到指定層級
- **🔽 全部展開**：展開所有項目
- **🔼 全部收起**：收起所有項目
- **只顯示新目錄**：隱藏舊結構項目

### 📁 匯入/匯出功能
- **📁 匯入**：瀏覽器端匯入新的 TOC 文件
- **📄 匯出**：導出當前展開狀態的目錄結構
- **實時解析**：客戶端即時解析和重建目錄

### 🎨 視覺效果
- **數字徽章**：括號中的數字美化顯示
- **結構區分**：不同數字格式的視覺區分
- **響應式設計**：適配不同屏幕尺寸

## 💡 使用技巧

### 1. 文件準備
- 確保文件使用 UTF-8 編碼
- 羅馬數字支持範圍：I-XV（1-15）
- 阿拉伯數字支持任意層級

### 2. 瀏覽器使用
- 打開生成的 HTML 文件
- 點擊 📁 匯入按鈕選擇新的 TOC 文件
- 使用控制按鈕管理目錄展開狀態
- 點擊 📄 匯出按鈕保存當前狀態

### 3. 層次結構
- 程式會自動忽略原始文件的縮排
- 完全基於數字模式判斷層次關係
- 混合格式文件會被正確分類和顯示

## 🔍 示例演示

### 命令行使用
```bash
# 使用當前目錄的 toc_full.txt
python toc_generator.py toc_full.txt

# 輸出到 demo 目錄
python toc_generator.py toc_full.txt -o demo

# 生成名為 index.html 的文件
python toc_generator.py toc_full.txt -o demo --html-name index.html
```

### 瀏覽器操作
1. 打開生成的 HTML 文件
2. 嘗試展開/收起不同層級
3. 使用 "只顯示新目錄" 切換顯示模式
4. 準備一個新的 TOC 文件，點擊 📁 匯入測試
5. 調整目錄狀態後，點擊 📄 匯出保存

## ⚠️ 注意事項

1. **文件編碼**：必須使用 UTF-8 編碼
2. **瀏覽器支持**：匯入功能需要現代瀏覽器（支持 FileReader API）
3. **文件依賴**：生成的 HTML、CSS、JS 文件需要在同一目錄下
4. **數字格式**：支持羅馬數字（I-XV）和任意層級的阿拉伯數字
5. **層次解析**：完全忽略原始文件縮排，基於數字模式判斷
