# tool/world_model —— 三千大千世界模型圖素材彙整

把 Tai 師父關於**宇宙結構／各天層／地獄／銀河系／須彌山／人間／感官取景**的全部敘述，
從兩套電子書的**生成產物**抽出，逐字彙整成一份可直接餵給大模型畫「三千大千世界模型圖」的素材檔。

## 為什麼讀電子書產物、而不是直接讀 PDF/Word

`wenda2_ebook/`（問答錄2，21 章）與 `ebook/`（九本著作＋《感恩與講經》卷首，10 卷）
已經由 `tool/word2ebook` / `tool/books2ebook` 從 `問答錄2/`、`books/` 的 PDF/Word 抽出並排版完成，
帶有乾淨段落、章節樹與穩定錨點。直接從那裡取字，可同時滿足三件事：

1. **完整**——兩套 `search_index*.json` 就是電子書的全量段落索引，可用來驗證抽取無遺漏。
2. **可回溯**——每一則素材都帶 `wenda2_ebook/NN_trad.html#<anchor>` 網址，可回原文比對。
3. **免維護**——源文件（PDF/Word）一變，重跑 `gen_all.py` 再跑本工具即可，不需另寫解析器。

## 用法

```bash
cd tool/world_model
python3 extract_corpus.py     # 電子書 HTML → build/corpus.jsonl（純文字語料）
python3 build_spec.py         # 語料 → build/world_model_spec.md（繪圖用精簡集，約 17 萬字）
python3 build_doc.py          # 語料 → build/world_model_{source,core}.md + .jsonl（完整庫存）
python3 verify.py spec        # 對照原始 HTML 驗證 spec：逐字 + 錨點
python3 verify.py source      # 同上，驗完整版
```

## 主題分層（T01–T16）

T01 宇宙總綱／T02 娑婆世界＝三千大千世界／T03 須彌山／**T04 世界的基本構造（核心）**／
T05 無色界四天／T06 色界十八天／T07 欲界六天／T08 人間世界／T09 地獄／
T10 餓鬼道與畜生道／T11 六道輪迴／T12 佛國與極樂世界／T13 物理層（光子）／
T14 感官層（六根・複眼）／T15 時間與劫／T16 神通所見。

分層方式見 `build_doc.py` 的 `THEMES`：

- `curated` —— 已知的宇宙觀章節**整節收錄**。同一節可出現在多個主題（內容確實橫跨主題）。
- `strong` —— 診斷性詞組，命中 ≥2 次進「核心」，≥1 次進「延伸」。
- `weak` —— 輔助詞組，只用於同分排序，不單獨觸發收錄。

## 已排除的舊說（`filters.py`）

Tai 師父改過銀河系／須彌山的說法：《坐禪1》最初說**須彌山＝銀河系**（銀河的黑洞＝須彌山頂），
之後修正為**須彌山是穿透銀河系、串接上下世界的那根柱子**。

兩版同時餵給模型會畫出被推翻的幾何，因此 `filters.py` 的 `SUPERSEDED` 會把斷言舊說的段落
排除（spec 與 source 兩份都套用）。全語料中斷言舊說的只有 **2 則**：

- `九本書/01_trad.html` 第01章 第03節「看我們的銀河系，整個銀河系就是須彌山……」
- `問答錄2/04` 結構與環境「《坐禪1》的時候，師父說須彌山就是銀河系啊……」

排除後不損失新版資訊——山腰＝四天王天、山腳＝人間、山頂＝忉利天帝釋天宮、
每個小世界各有一根須彌山，這些都另有段落承載（例如 `問答錄2/21` 2026-03-02 的回答）。

`filters.py` 同時定義 `CURRENT`（新版表述），可用來反向檢查新版是否仍在產出中。

## 產出原則

- **逐字**：不改寫、不刪節、不摘要、不翻譯。`verify.py` 會把每一行回比原始 HTML。
- **不漏字**：拆成多段的提問（生成器會加 `-2`、`-3` 錨點）必須合併渲染，否則會整段掉字。
- **可回溯**：每則標示提問者、時間、全部錨點。

## 驗證基準

`extract_corpus.py` 的抽取結果對兩套 `search_index*.json` 達成 **100% 覆蓋**
（`問答錄2` 18,653 筆中僅 1 筆未中，該筆在原始 HTML 內本就是空的提問框）。

`verify.py` 把產出的每一行回比原始站上 HTML：

```
verify.py spec    →   679 則／1,634 行，逐字 0 缺、錨點 0 壞
verify.py source  → 6,553 則／20,477 行，逐字 0 缺、錨點 0 壞
```
