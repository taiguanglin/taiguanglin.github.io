# 第12章「佛门修行」分類準則

> 969 則、8 個 L2（fallback 收尾章）——由上半（12-01～12-06）與下半（12-07～12-08）兩個檢驗代理拼合。

## 一、章級定位：12＝fallback 收尾章，先排除專章

12 章收「佛門通識」：凡專章（01–11）有明確歸屬的問題一律先歸專章，12 只收剩餘的修行周邊綜合問題（法門選擇、佛菩薩常識、佛教百科操作、外道比較、跨法門修行 meta）。以下情況**不該落 12**：

- **02羯磨**：具體病症成因與對治（業障病各 L3）、向佛菩薩求願/滿願、加持與感應原理、懺悔拜懺、冤親債主、非人干擾、消業方法。問「病、求事、業」→02，即使問句含「念經」「佛菩薩」也不改判。
- **03发心**：發大願的內容、方法、不退轉、授記成佛；12-01 只收「目標設定、信心、態度、重點」。
- **04世界**：死後去處、超度亡靈、入葬祭祀、臨終助念、六道生態（天人/鬼王/妖精作為**物種**）、彌陀/釋迦/文殊普賢/觀音/勢至等極樂娑婆**團隊成員**的身份。注意：「修地藏法門最後去哪」因主體是法門選擇→12-03（見證據）。
- **05戒行**：吃素飲食、戒淫、受戒儀式/戒體/犯戒、墮胎。「供水果算不算偷盜」主體是供佛→12-05。
- **06功德**：放生、施食、造塔造像（作為功德）、火供、回向、功德校量；12-05 只收佛像供具的**操作與禮儀**。
- **07經咒**：指名經咒的念法/遍數/出聲默念/感應/經書處理。**「12-05 名詞」vs「07 經咒」邊界**：指名某經某咒的**念誦與感應**→07；泛佛學名相與公案（见惑思惑、一生补处、正法眼藏、龙华三会、法华三昧證相、達摩傳法偈、《阴律无情》真偽）→12-05；「經裡這句什麼意思」→12-05，「這部經怎麼念/念幾遍/有何感應」→07。
- **08–11**：呼吸/磕頭/雙盤/禪定的姿勢、時間、身體反應、次第與法門細節（含念佛/觀佛/參思情）；**跨法門**的功課表/作息/先後搭配→12-01。
- **12 下半（非本範圍）**：修行融入生活（家庭/工作/養生/解夢/靈異親歷）→12-07；TAI 師父個人（傳法安排/皈依供養質疑）→12-08。「皈依 TAI 師父」→12-08，一般皈依儀式效力→12-05。

- **佛缘与根器/前世修行/功力(31)**：根器判斷、前世修為延續與找回、三種姓、智慧來源、學法快慢。關鍵詞：「前世有修」「根器」「种姓」「找回前世修为」「智慧是什么决定的」「泪流满面」。易錯：與具體人的緣→02；選相應法門→12-03。
- **理悟/明心/见性/开悟(16)**：開悟定義、悟後起修、見性判斷、頓悟漸悟、禪宗悟境與四禪關係。關鍵詞：「明心见性」「开悟」「悟后起修」「顿悟」「见本来面目」「拈花一笑领悟到什么」「无心是什么状态」。易錯：妄想習氣對治→01；禪定次第→11。
- **修行的利益/境界(7)**：修為與容貌/衰老、開闢小世界、境界徵驗。關鍵詞：「返老还童」「修为高低」「容貌」「开辟一方小世界」「衰老慢」。易錯：打坐身體反應→10；壽命與中脈理論→11/12-06。

節間邊界：目標信心 vs 懈怠＝「設定」vs「執行中斷」；懈怠 vs 功課＝「做不做」vs「怎麼排」；求法拜師 vs 不去破邪＝「找正」vs「斥邪」；求法拜師 vs 正視神通＝「假師騙局」vs「現象本身」。

灰色地帶：

- 出體體驗：快睡著/日常 → 12-07-05；打坐中 → 11 陰神陽神。
- 睡前/打坐代替睡覺/幾點坐 → 10；睡姿床鋪失眠 → 12-03-03。
- 靈異歸因「被干擾/冤親債主」→ 02；純經驗求解 → 12-07-05。

- 「Cindy: 怀疑师父的人是不是有业障」收 08-02 而非 08-04：08-04 是**師父端回應質疑**，質疑者的對待問題在 08-02——分類時看問答歸屬端。

規則（R=正、N=負）：
- **R1** 問「什么因果/是不是业/消业吗/为什么是我」→ 02業障病；「怎么治/好不好/有用吗/副作用/怎么养生」→ 12-07-03。病名不決定歸屬，動詞軸心決定。
- **R2** 為自己/家人的喪葬、墓地、素宴、捐體做決策 → 12-02-04；亡者去處、祭祀效力、骨灰對亡人影響 → 04-04-08。
- **R3** 睡眠是打坐課表變量 → 10；睡眠是主題（姿勢/品質/作息精神）→ 12-03-03。吉祥卧歸 12。
- **R4** 夢＝發願效驗 → 03；夢＝戒律考試內容 → 05；夢＝類型判定/機制（清明夢/夢考/無夢）→ 12-04-02；夢象求解 → 12-04-01；亡者/胎兒/寵物主動入夢 → 12-04-03。
- **R5** 打坐中的幻覺境界 → 11；日常一次性神秘經驗 → 12-07-05；歸因非人干擾並問對治 → 02。
- **R6** 問命理/風水/民俗現象本身 → 12-02-06；問自己命運定數/改劇本 → 04-03-08；問向佛菩薩求的方法 → 02-03-03。
- **R7** 主語 TAI 師父（計畫/日常/皈依/質疑）→ 12-08；主語傳法機理/職業/組織 → 04-05；主語其他高僧 → 12-05。
- **N1** 不可因文本提到「打坐/双盘」就歸 10——看主題主體（站樁、補氣血、經絡知識實例都收 12-03）。
- **N2** 不可因提到「梦」就歸 12-07-04——先查夢的來源主體與問句軸心（R4）。
- **N3** 不可把「修行人問的身體問題」全歸 10/11——生活醫療保健（療法、睡眠、身體機能）是 12-07-03 的本職。
- **N4** 「2、」等編號開頭是拆分子問題，須按該子問題自身軸心歸節，不可連坐前一子問題的歸屬。

## 九、拆分觀察

12.html 全章 969 問；「修行与生活」錨點起至檔尾（=本報告範圍 12-07+12-08）共 423 問（316+107，與主題樹吻合）。

- 範圍內以「N、」編號開頭：122/423 = **28.8%**。分佈：1、19；2、70；3、19；4、5；5、4；6、1；9、1；其他編號形式（「问题2、」「第13问」）3。
- 全章對照：264/969 = 27.2%（1、33；2、159；3、47；4、12；5、10；6、2）——本範圍與全章比例相當。
- 「2、」開頭（70）**遠多於**「1、」開頭（19）。原因實測：拆分後第 1 子題通常保留問候語（「师父！ 1、发大菩提心后…」「顶礼Tai师父！ 1、弟子现在每天…」），故不以「1、」起頭——範圍內帶問候語+內嵌「1、」者 27 則；帶問候語+「2、」者 **0 則**，第 2 題起一律裸編號開頭。
- 範圍內「2、」全文出現 70 次、全部位於開頭 → 證明「2、」幾乎全是拆分痕跡，而非單則內的多問並列。
- 特徵記錄：① 同一用戶跨相鄰條目連續編號（偶米大、逐月A、阿难乎、安_Tai、掌南飞 皆見 1、2、3、序列）；② 出現「9、」→ 原訊息可含 9+ 子問題、被重度拆分；③ 拆分使一則原訊息的子問題散落不同 L4（如逐月AAA 的職業選擇與英語學習同落 02-03，亦有跨節案例），歸類必須逐子題判；④ 證據檔兩處「(此问题丢失或未收集到)」與節計數差額（传法安排42 vs 40则、病症疗法33 vs 32则）顯示拆分/收集時有遺失。
