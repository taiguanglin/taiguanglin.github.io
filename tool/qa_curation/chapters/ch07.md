## 一、章級定位

**一句話定位**：07 收「念誦這個行為」——凡主角是「誦經／持咒／念聖號」（含為誰念、怎麼念、念出什麼反應、經書與具體經咒本身），且主問不是禪修法門、不是往生信願行，就歸 07。

### 1.1 收錄
- 念誦的利益與機制：為何有功德、佛菩薩如何感應、咒語是什麼／誰造的
- 念誦操作與變因：選經選咒、出聲默念、讀音版本、速度數量、姿勢地點時間、媒介（電子／木魚／轉經輪）、前後真言、心態戒行、聽／抄替代
- 念誦引發的身心反應、感應境界、懈怠妄想干擾的對治
- 為其他眾生念誦（亡人／鬼道／活人／畜生）及誦後回向環節
- 經書作為物件：助印流通、保存筆記、翻譯、燒毀損壞處理
- 指名經咒的一切單部深問（內容義理、版本真偽、效果、修法）→ 按 L4 細分

### 1.3 「同一句念佛」動機判準（已驗證）
- 求生淨土為主問（往生把握／品位／接引／臨終）→ 04

### L2-1 念诵的利益与原理（21）
- 收：念誦為何有功德／加持原理；咒語作用機制（非聲音、是與佛菩薩感應）；咒是誰造（八地菩薩編咒）；誦咒後情緒減輕的歸因；「讀經沒用」言論是否邪見；念咒根本目的（保護自己還是入定）
- 關鍵詞：原理、为什么…功德、加持、感应、编辑咒语、目的
- 邊界：具體某咒能不能驅魔／治病的效果比較 → 经咒的区别与选择（實證：掌南飛「只有楞严咒能驱魔吗？我念秽迹金刚咒淫欲减少了」落此節——多咒功能歸因）；向佛菩薩求願怎麼求 → 02；打坐念佛的感應 → 11。**原理類主問壓過具名經咒**（實證：「十一面观音根本咒…念咒的根本目的是什么」在此節，不在大悲咒組）。

### L2-3 障碍/反应与应对（37）

**L3 身体不适/变化（15）**：念誦時打嗝、流淚、哈欠連天、犯困、發冷、胸悶噁心、腰疼、劇咳失聲、額頭髮緊、小腹膜動（胎息？）、長期念咒傷心臟；含「這是不是消業／招到什麼了」。邊界：打坐引發 → 10；一般病症 → 02 業障病／12 治病養生；本節限「念誦當下引發」。
**L3 情绪/意识变化（5）**：誦咒悲泣不止（眾生太苦）；白天念經念進第八識、醒後心裡還在念；外音變咒音是否魔境；誦楞嚴咒後向家人發火；誦經突然嗜睡失控。邊界：打坐中的境界／幻覺 → 11；由念誦直接引發才收。
**L3 殊胜感应/神通（10）**：讀經入另一空間／震動／熱浪加持；持咒見光球影像；誦法華經後見金龍；念楞嚴咒得見鬼道能力；夢中持咒脫困算不算授記；「一直沒感應是否業障重」。**判別**：問「我出現了 X 現象，怎麼回事／好壞」→ 本節；問「這個咒怎麼修／多少遍／背後是誰」→ L4。出體 → 11；純解夢 → 12。
**L3 应对妄想/懈怠/干扰（7）**：念經偷懶看手機、注意力差／大舌頭念不順的對治、被干擾後不敢再念、咒音模糊囫圇、持咒被狗咬是否不適合此咒。收「**怎麼辦**」（求對策）；「有沒有影響」→ 心态节；泛論修行退轉 → 12。

### L2-4 为其他众生念诵（24）

**L3 亡人/鬼道众生（11）**
- 收：為亡父／亡親念地藏經（含「專為一人念」的動念）；夢中亡親討經、念多少；給鬼道念經、邀鬼來聽；不懂經義鬼能否讀取；默讀旁聽鬼能否聽到；為剛死動物念寶髻如來；自發為陌生亡者念經是否觸怒其冤親債主；聽經的鬼會否賴著不走
- 關鍵詞：为亡、给鬼道、来听经、回向给父亲、宝髻如来
- 邊界 vs 04 超度亡灵：**主體視角**——問「我怎麼念、念給誰、他收不收得到」→ 07；問「他現在在哪、能否超升、法事／牌位有沒有用」→ 04。實證：同為「為亡者念經」語境，04 收「轮回到饿鬼道的众生有修行人为他念经能超升吗」（問亡者去處），07 收「為父親讀 20 部地藏經怎麼沒感覺、專為一人讀」（問念誦方式）。

**L3 他人或其冤亲债主（6）**：為活人（侄兒／老人／抑鬱小孩／生病朋友／母親）念誦回向；回向給他本人還是他的冤親債主；為不信佛者念有無損害；為人念後自己不舒服；為其錄音循環播放。邊界：回向通用操作 → 06；受益者已死 → 亡人/鬼道众生。
**L3 畜生道众生（1）**：給活的動物念誦／動物聽經（狗天天聽地藏經心經能否轉人身）。邊界：已死動物 → 亡人/鬼道众生（實證：給剛死動物念寶髻如來在亡人節）；放生念儀軌 → 06。
**L3 念诵后的回向（6）**：誦畢後經書附帶的回向文／真言還念不念；地藏經後面回向文的爭議（會否引來討債）；誦楞嚴咒回向極樂如法嗎；一天多次誦後回向、回向時想不想身形。邊界 vs 06 功德回向：**與誦經程序綁定**的回向環節 → 07；回向通用方法（時機／大小回向次第／回向文寫法／七分之六）→ 06（灰色地帶 #2）。

**L3 具体经咒（123）→ 14 個 L4**

**L4 歸類總則（已驗證）**
1. **按經典／咒語名歸類**：問題中指名的經或咒是唯一錨點；內容義理、版本真偽、效果、修法、感應史，凡指名一律進該 L4，不因「是義理題」改去 12（實證：「《维摩诘经》核心讲什么」「楞伽经第二十四课十二妄计性」均在對應 L4）。
2. 同組併節慣例（新增題先配組）：地藏經＋滅定業真言（法門經＋專屬咒）；心經＋金剛經（般若部）；圓覺經＋楞伽經（師父正在講的兩部）；僧伽咤經＋禮佛大懺悔文；華嚴經＋普賢行願品；淨土五經（彌陀系經典＋會集本＋彌陀大心咒）；楞嚴經＋楞嚴咒（經咒一體）；大悲咒＋六字大明咒＋白衣大士神咒（觀音咒群）；穢跡金剛咒／金剛薩埵心咒／尊勝咒／寶篋印咒（消業超度密咒群）；加倍咒／變食咒／度肉咒（儀軌輔助小咒）；法華經；長壽滅罪經；其他经咒（兜底）。
3. 群組歸屬以**本書既有歸屬**為準，勿按教界慣例重分：普賢行願品雖屬「淨土五經」之一，本書歸華嚴組；淨土五經組實收彌陀三經＋會集本＋「修阿弥陀佛大心咒是不是往生方便法门」。
4. 多經名共現取**主問經**：常住真心同提《金剛經》與《楞嚴經》四清淨明誨，主問是金剛經滅度義 → 心經/金剛經節。
5. 新經咒配對序：觀音系咒 → 大悲咒組；消業／超度密咒 → 穢跡金剛組；淨土經典 → 淨土五經；小功能儀軌咒 → 加倍咒組；其餘 → 其他经咒（同類累積多則再議新開 L4）。

## 三、命名慣例

- **層級語體**：全部簡體（與全書 12 章目錄一致）、口語化、無編號前綴；章名「念诵经咒」為動賓短語。
- **L2**：主題名詞組——「念诵的利益与原理」（行為＋兩個抽象軸）、「方法及对效果的影响」（並列連接「及」）、「障碍/反应与应对」（現象/現象/動作三段式）、「为其他众生念诵」（介賓＋動賓）、「有关佛经」（「有关＋對象」容器式）。
- **L3**：三種構式——①斜槓並列同維度詞（「姿势/地点/时间环境/边干其他」「心态/戒行/清净程度/经文理解」：名詞段在前、口語動賓段收尾）；②「A与B」並列（「经咒的区别与选择」「念诵与听经/抄经/施食」「印经与流通/保存/笔记/翻译」）；③時序後綴「后的X」（「念诵后的回向」）。
- **L4**：具體經名／咒名用「/」串接同組（「大悲咒/六字大明咒/白衣大士神咒」），兜底節「其他经咒」；單部經用全名不縮寫（「佛说长寿灭罪护诸童子陀罗尼经」）。
- 新增節沿用既有構式，勿造新格式；經咒名從原文（含《》書名號）。

## 五、灰色地帶

1. **只持 A 可否替代 B**（區別與選擇 vs A 的 L4）：雙向案例實測——常住真心「求生西方持大悲咒好還是繼續楞嚴咒」→ 区别与选择；Elaine「只持诵楞严咒…代替读《地藏经》消业吗」→ 楞嚴咒 L4。指引：並列兩具名對象、求「哪個好／區別」→ 选择节；主語聚焦單一功課、求「可不可以」→ 該部 L4；無法判定時以主體正在修的那部 L4 為預設；有答案文本時以師父答案主軸為準。
2. **回向雙棲**（06 vs 07）：「一天數次讀經咒何時回向」實測落 06。界線：回向作為通用功德操作（時機／次第／寫法／校量）→ 06；誦經程序內的回向環節（經書附帶回向文、為特定眾生誦後回向）→ 07。
3. **為亡人念誦 vs 04 超度亡灵**：主體視角（我怎麼念／他收不收得到）→ 07；客體視角（他在哪／能否超升／法事牌位）→ 04。同語境雙向案例已驗（見 L3 亡人節）。
4. **感應現象 vs 經咒深問**：讀法華經見金龍 → 殊胜感应；念楞嚴咒背後是誰／十萬遍療程 → 楞嚴咒 L4。判詞：「我看到／感覺到 X，怎麼回事」→ 障礙三節；「這個咒怎麼修」→ L4。
5. **打坐念誦**：「打坐时／静坐中」念經咒 → 11；坐著念經的姿勢與時長 → 07（「双盘念经两小时影响健康吗」實測留 07）。
6. **夢中念咒**：現象／授記歸因 → 殊胜感应；念速快慢 → 断续/速度/数量；純解夢 → 12 梦境。
7. **信心與懷疑**：「懷疑經則誦經效果不大」→ 07 心态节；「信则有 vs 客观存在」教理之辯 → 12（實測落 12）。
8. **拆分子問題的回指**：代詞指前文的經咒時取本段最近具名對象；仍無法判定時保守歸 L3 對應節而非 L4。
9. **長訊息多主題**：以主問句＋師父答案主軸定位（橘子和香蕉案例：夢境開頭、實問念一年地藏經）。

## 六、給 LLM 的操作規則

**判定程序（依序，先中先贏）**
1. 「打坐时／静坐中／禅修中」＋念佛念經念咒 → **11**
2. 主問是往生／臨終／助念／亡者去處／法事牌位 → **04**
3. 主問是念誦作為修福手段比較、求世間福報、回向通用法 → **06**
4. 經書物件（印／流通／保存／燒毀／處理）→ 07 有關佛經前兩個 L3
5. 為亡人／鬼／活人／畜生念誦，或誦後回向環節 → 07 為其他眾生念誦
6. 「我念了之後出現 X」現象歸因或求對治 → 07 障碍/反应与应对
7. 指名單一經咒的深問（修法／遍數／版本／偽經／背後菩薩／義理）→ 07 具体经咒對應 L4
8. 並列 ≥2 具名經咒求區別／抉擇 → 07 经咒的区别与选择
9. 原理／功德機制／咒語總論 → 07 念诵的利益与原理
10. 方法操作變因 → 07 方法各 L3（聲／音／數量／媒介／前後真言／處／心／聽抄施）
11. 皆非 → 考慮 02（求願加持／懺悔拜懺）、05（戒）、08/10（呼吸與打坐）、12（名詞／夢境／生活）

**正面規則（做）**
1. 主軸是誦經／持咒／念聖號的行為面 → 一律從 07 起判
2. 指名經咒先查 L4 速查表；配不上 → 其他经咒
3. 編號前綴（「2、」「③」）僅提示拆分：子問題獨立分類、不繼承兄弟主題、代詞取最近具名對象
4. 長訊息讀完整文字，以主問句定節；開頭情境不決定歸屬
5. 同批拆分的多個子問題可能落在不同章節，預期並允許這種離散
6. 輸出標題遵循命名慣例（簡體、斜槓並列、L4 經名串）
7. 規則衝突時以「主問句＋答案主軸」為最終裁決，再按程序順序

**負面規則（不做）**
1. 不因「打坐」出現就整則歸 11——主語是念誦姿勢（坐著念經）仍歸 07；反之「打坐中念佛」必去 11
2. 不因「地藏經」出現就塞進 L4——初學順序／選擇比較／念給鬼道等語境優先
3. 不因「往生极乐」動機修飾就把方法題推去 04
4. 不收戒律、吃素、放生、施食儀軌本身（05／06）；07 只收其「影不影響念誦效果」
5. 不把不指名經典的名詞／判教／公案歸 07（→ 12）
6. 不把打坐身體反應、解夢、一般治病歸 07（→ 10／12／02）
7. 不為兜底以外的經咒新造 L4，除非同類已成組
8. 不用繁體命名新節標題（全書目錄為簡體）
