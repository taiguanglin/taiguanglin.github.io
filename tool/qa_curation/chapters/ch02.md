# 第02章「羯磨(业)」分類準則

## 0. 章況速覽
- 樣本：wenda2_ebook/02.html，h1章→h2=L2→h3=L3，**本章無L4**。結構：1個「本章目录」假節＋6個L2＋35個L3＝42節、789則。
- L2量級：业的复杂性(315)、业障病(161)、业与加持(105)、消业的方法(103)、业的原理(63)、业与结缘(42)。
- 全章語義軸（師父模型）：**業＝人際互動中產生並殘留於對方阿賴耶識的情緒/虛妄，須經後續互動了結**。分類以「該問聚焦的業作用面」為軸：機制→結緣→加持→消業→世間顯相→疾病顯相。
- 拆分特徵：789則中**207則以「N、/N./N:」開頭**（26%），另有「一、二、」「問題N：」「提問N、」「第2112問:」「• QN：」等。常客多拆分者：掌南飛17則、空空無我14、果慧12、三日空11、偶米大10——同一人訊息的編號片段**分散落節**（如心畫世間Q1→工作業、Q6→修行善行消業、Q8→凡夫消業、Q9/Q10→感應）。

## 1. 章級定位

### 1.1 收什麼（主語是業，或以業為求解對象）
1. 業的機制：產生條件、作用範圍、定業/不定業、數量與利息、業與習氣性格。
2. 結緣：什麼互動算結緣、了緣、業緣vs佛緣、凡夫/再來人結緣取捨、與師父本人的緣。
3. 加持：原理、傳遞、**向佛菩薩求世間願的方法**、感應的有無與辨真偽。
4. 消業：邏輯與表現、凡夫/再來人消業、懺悔拜懺、隨順忍辱、善行修行消業（打坐磕頭念經放生朝聖）。
5. 業的世間顯相：家人感情婚姻、工作錢財、不順共業、不敬正法、修行牽出業障、非人干擾、冤親債主。
6. 業障病：提問者/親人**具名疾病**的因果與救治，按人體系統分科。

### 1.2 不收什麼（劃給誰）
- 六道輪迴、中陰身、亡靈去向、**超度亡人**、入葬祭祀 → 04。02只收「非人/債主對**活人**的干擾討報」；墮胎/嬰靈超度 → 05-戒殺。
- **破戒行為本身**與其果報（殺/淫/盜/妄、吃素飲食）→ 05。02只收該行為作為業理討論或職業/生活情境（例：賣青蛙的生意、感情裡的邪淫後遺）。
- 放生儀軌、功德校量、回向方法 → 06。02只收「放生作為消業手段」的原理與他法比較。
- 打坐/磕大頭/呼吸的**練習方法與練習反應** → 10/09/08。02只收「雙盤疼是不是消業」的業理、或「修行把業障牽出來」框架。
- 念經持咒的方法、選擇、為眾生念誦 → 07。02只收念誦作為求願/消業手段。
- 發大願/菩提心/往生之願 → 03；往生細節 → 04。
- 生活實務處理（怎麼相處/教育/擇業）無歸因問句 → 12-紅塵瑣事；**同一生活域但以因果為提問軸**（是什麼業/怎麼消）→ 02。
- 禪定境界、陰神、神通 → 11。夢的寓意解讀 → 12-夢境（干擾/討報框架才留02）。

### 1.3 三角邊界：02業障病 vs 12-03治病養生 vs 10身体的反应
判準＝**錨定對象三問**（樣本歸納）：
1. 錨定「具名的病＋病痛部位」、且問因果/佛法救治 → **02業障病**（按部位分科）。例：「母親三次中風偏癱，與因果相關嗎？怎麼幫她恢復？」
2. 錨定「療法/養生方式/身體機能」，無個人具名疾病與歸因問句 → **12-03治病養生**。實證12的樣本問「中醫與安東尼療法的歸因分歧」「中醫怎麼誕生/該不該學」；其L4（病症与疗法/运动站桩/睡眠睡姿/行站坐姿/身体结构机能/器官移植）全為方法論軸。
3. 錨定「練習中/後出現的反應」→ 該練習章身體反應節。實證10樣本：「打坐二十分鐘腳麻手心發黑，能不能給個練習方案」——主訴是練習反應，不是疾病。
4. 混合題歸屬：
   - 「打坐/磕頭能不能治我的X病」→ **02**（錨定X病，修行只是治法）。實證：「肺結節能否通過打坐練呼吸調理」「頸椎椎孔狹窄磕大頭還能治愈嗎」「近視眼能通過磕頭誦經改善嗎」全部在02，未落10。
   - 「修行後一堆事接連出現，是不是業障現前？」→ **02-修行牽出業障及應對**（複數症狀＋歸因框架），不拆到10/09。
   - 「有病能否練/術後打坐」→ 10-術後病後打坐；「病本身的因果與救治」→ 02。兩面都問看主問動詞。
   - 10-伤病与修复-疫苗后遺症修复 vs 02-免疫系统：「打疫苗後身體差、修行後退」在02；「打坐修復疫苗後遺」在10——看主問是治病還是修復練習。

## 2. 逐節準則（每節：收錄主題｜關鍵詞｜邊界｜易錯）

### 2.1 業的原理(63)
- **L3 業的產生/作用範圍(40)**：收「業何時產生、誰背業、作用範圍」的判定與思想實驗。關鍵詞：算不算業/會不會背因果/干擾別人因果/單方情緒/無人參與（浪費作弊撿垃圾）/A與B兩人設例/罵人壞人有果報嗎/佛頭疼三日。邊界：問「怎麼消」→消業的方法；「罵善人vs罵惡人果報輕重」是定量題→下一節。易錯：大量A/B代號思想實驗無個人處境，勿當「無歸屬」漏收。
- **L3 業的性質/數量/利息(16)**：收定量與性質：定業/不定業、利息疊加、越晚消越多、善惡業判準、境界越高帶業越少、果報增長廣大。關鍵詞：定業、不定業、利息、帶幾點業、四的28次方。易錯：「嬰兒性格是不是白板」→業與習氣。
- **L3 業與習氣/性格(7)**：收性格稟性天生傾向與業的關係：一見如故/一見討厭、天生虐待傾向、天生怕蛇、性格是業習還是劇本。邊界：對治習氣的方法→01；單一習氣對治（淫欲等）→05/10/11。

### 2.2 業與結緣(42)
- **L3 報身結業緣(18)**：收「什麼互動算結緣」判定：見面/目光對視/供養/直播互動/為中陰身念經/鬼道眾生聽經/輕微互動要否角色輪轉。關鍵詞：算不算結緣、了緣、見面就是結緣、廣結善緣。易錯：與佛菩薩/與師父結緣→下兩節。
- **L3 業緣與佛緣不同(5)**：收理論辨異：佛墮落時他佛無緣不能幫、報身才能結緣、化身結緣、法緣是什麼、緣分深淺判讀。易錯：具體「怎麼加深與菩薩的緣」→加持/求願。
- **L3 凡夫多結善緣(7)**：收「凡夫該不該/敢不敢結緣」的取捨與心理：幫陌生人、心理助人工作、放生多結緣業漲嗎、怕造業變「自私」的糾結。主語必須是凡夫。
- **L3 再來人慎重結緣(2)**：同一問題但主語是再來人/證果者（龐蘊沉財、再來人為何少結緣）。
- **L3 與TAI師父的緣(10)**：收弟子與師父本人的緣：讀書聽法算不算結緣、如何加深、師父關注1000人的用意、對師父聲音起執著、蹭緣。易錯：訊息裡「師父12日答疑是否遺漏1051樓」＋長故事——框架是與師父的互動，留此節，不按故事內容拆。

### 2.3 業與加持(105)
- **L3 加持的原理(13)**：收「是什麼/為何有效」：加持原理、為何念佛號供像能連接、共修磁場/電磁場、佛在世加持大、佩戴經文、極樂團隊防魔、無緣能否被救。易錯：問「多少點/怎麼傳到」→傳遞。
- **L3 加持的傳遞(10)**：收路徑與量：層層傳遞條件（①輪迴裡②互相參與③產生情緒）、加持力點數量化、空間距離、極樂有親戚、諸佛同體他方佛、親友能否透過我得極樂加持。與原理節的分界＝機制vs路徑。
- **L3 向佛菩薩求愿的方法(52)**：收具體求願操作（本L2最大節）：求考運/財務自由/換工作/父母保佑/懷孕/婚姻、怎麼求才靈、求願要多少放生供養兌換、灌頂水、《观世音菩萨感应灵课》、求了不靈怎麼辦。易錯：發大願/往生之願→03/04；為亡者求→04；「感應通不通」→感應節。
- **L3 与佛菩萨的感应(30)**：收感應有無與真偽：修多年無感應、夢中點化真偽、冤親債主假扮菩薩、念咒不靈信心喪失、腦中答案自動浮現、如何區分感應與錯亂幻覺。易錯：夢境內容求解→12-夢境；此節主軸是「感應通道」。
- 節內通行：先分「求（我求菩薩辦事）」vs「感（菩薩有沒有回應我）」——動詞定節。

### 2.4 消业的方法(103)
- **L3 消業/轉業的邏輯與表現(35)**：收消業機理判定（多A/B設例）：殺人後回向算不算消、B不恨了算兩清嗎、地獄受報算不算消、受報與消業之別、損失更大消更多嗎、大報小受、命運編輯視角。關鍵詞：消業/受報/了結/兩清/報仇幾次限制。
- **L3 凡夫消業(21)**：收凡夫個案「我這段業怎麼消」：小時偷東西、得罪人無法當面懺、偷已故母親的錢、被動造惡業、扇自己嘴、業障來時集中念地藏菩薩、化太歲是否外道。主語＝凡夫＋具體舊業。
- **L3 修行善行消業(打坐磕頭念經放生朝聖)(11)**：收「哪些修行/善行能消業、為何、多快」的比較：打坐消業原理、雙盤疼消一分業?（邪見?）、放生稀釋惡業、持咒加持力稀釋、念佛滅80億劫罪、朝山轉山滅罪、義工苦修vs誦經。易錯：括號＝收錄手段清單；帶具體腿疼處理求方案→10。
- **L3 忏悔与拜忏(16)**：收懺悔的操作與效力：當眾vs默默、業由心起將心懺、往生前拜懺、取相懺、向冤親債主懺悔、道歉未獲回應、每天功課加懺悔、懺文選擇、拜懺後偏頭痛是消業嗎。
- **L3 随顺忍辱(12)**：收忍辱/隨順作為消業法：無生法忍是什麼、隨順底線、該忍還是該懟、被強姦可否報警、老實人吃虧、行俠仗義與六度之忍。易錯：無生法忍在此是消業法角度；入定境界討論→11。
- **L3 再来人消业(8)**：主語是羅漢/菩薩/佛的消業：不還果怎麼消、投胎消業安排、止疼與割肉喂鷹、等覺消業量、兩阿羅漢互消。凡夫提問也收，只要**被消業的主體**是聖者。

### 2.5 业的复杂性(315)（本章最大L2：業在世間的顯相）
- **L3 家人/感情/婚姻的业(83)**：收以血親/配偶/戀人為對象的業：原生家庭、被虐待/打父母運氣變好、父母克子女、代孕、情劫、閃聚閃散、離婚了業沒消、情債、子女數命定、二胎牽絆、與父親怨氣、怎麼跟異性徹底了緣、婚內邪淫後遺（感情向）。易錯：問破戒標準→05-戒淫；問相處技巧無歸因→12-紅塵瑣事。
- **L3 工作/职业/钱财的业(88)**：收以職業/錢財為載體的業：打工還社會債、失業是能力還是業力、老師打學生算造業嗎、吧主刪乞討帖、心理諮詢師沾頭痛、炒股討債、造武器、賣青蛙生意、扶人被訛、水滴籌、補財庫、崗位降級是業障嗎。易錯：四大職業選擇/規劃→04-傳法的職業。
- **L3 不顺/世间业/共业/行侠仗义(28)**：收群體與大尺度：戰爭屠殺的共業、馬航大災難、侵華日軍、疫苗政策決策、天象星象與業力、行俠仗義/正當防衛殺人、救人絕育流浪貓涉因果、業障重多域複合（感情+事業+失眠）、別人找上門的不順都算業報嗎、重男輕女。易錯：單一生活域的問題→前兩節；「業障很重一事無成」多域複合歸此。
- **L3 不敬/攻击正法/信受传播邪法(14)**：收謗法類：聽邪師、小乘謗大乘、罵人王、親友撕經書掰電腦、誹謗大修行人、誹謗地藏經法師、傳播邪法後補救、邪法印記。易錯：「初禪能不能避免癌症＋禪師臨終懺口業」複合題在此節——按主軸（口業/謗法）不按開頭詞（癌症）歸腫瘤節。
- **L3 修行牵出业障及应对(24)**：收「開始修行後業障現前」：皈依後全家出事、讀地藏經招來病、精進就病魔失眠、雙盤→磕頭→誦經接連被障（膝痛+關節響+疑心聲音）、承受力反降、大考節點在哪、冤親債主怎麼知道你修行、業報提前+親人受影響。易錯：單一練習反應問機理→10/09；多症狀＋「是不是業障現前」歸因→此節。
- **L3 非人干扰及应对(24)**：收非人對人干擾：睡中被非人搬腿、無身眾生做男女事、靈魂被拉走、雞皮疙瘩是靈體靠近、阿修羅附體、大仙薩滿對治、陰性體質吸氣、遇鬼魔念什麼（穢跡金剛咒vs佛號）、念佛機超度非人、夢見算命師光球。易錯：夢的寓意解讀→12-夢境；有具體「討某筆債」主體→冤親債主節。
- **L3 冤亲债主及应对(54)**：收「特定債主討報與化解」：保家仙牌位處理、債主附在孩子身上討債、孩子高燒噴白沫疑奪舍、打坐受傷被診為業障、欠蚊蟲虱子債、共修時債主抖動、如何知道不順是業力還是債主干擾、冤親債主在鬼道怎麼知道你修行。易錯：為已故親人求去處/做法事→04-超度；墮胎嬰靈→05；孩子病但無債主框架→業障病-兒科。

### 2.6 业障病(161)——分科規則（已驗證）
**規則：L3 分科按「提問者主訴的病痛部位/系統」歸類**——不按療法、不按歸因。實證：同為「打坐/磕頭能不能治」——近視→眼耳鼻喉/牙；頸椎→骨科；痔瘡→消化道；月子病→婦科；耳鳴（自問腎氣不足）→消化道/肝/腎。同一人多問拆開各歸各科（無名Q3水腫、Q4耳鳴同落腎系節，因其自述腎氣/水腫屬腎）。歧義時跟隨提問者自己點名的系統（含中醫歸因）。
- **L3 疾病的原因及应对(9)**：收不落具體部位的一般疾病論：生病都是業報嗎、疾病因何產生、癌症年輕化因殺業、對體內眾生念四句話、替病人尋祕方是否介入因果、菩薩云何慰喻有疾菩薩、手術算消業嗎。有具體部位→各分科。
- **L3 儿科/遗传病/皮肤病/头发(22)**：孩子病、遺傳/基因病、自閉罕見病、唐氏（多發先天障礙歸兒科，即使含耳聾）、發育遲緩、蕁麻疹、灰指甲、脫髮、遺傳病是家族共業嗎。易錯：孩子病＋債主附體討報框架→冤親債主節。
- **L3 眼耳鼻喉/牙(19)**：鼻炎、視網膜裂口/閉眼雪花點、牙齒脫落是口業嗎、近視、左眼失明、師父會生病嗎（拆分孤兒片段）。
- **L3 骨科/脊柱/神经系统(10)**：膝蓋痛、股骨頭壞死、頸椎狹窄、腰間盤突出、類風濕、全身關節響。
- **L3 心/肺/脑/血管/中风/瘫痪(27)**：中風偏癱、腦出血昏迷、心臟血栓手術、冠心病、動脈硬化、肺結節、肺大泡、白痰、靜脈曲張、心律不齊。
- **L3 消化道/肝/肾/虚劳/贫血(16)**：痔瘡、闌尾糞石、地中海貧血、透析、小腸壞死手術、胃痛經絡、增重失敗、臉黃、水腫、耳鳴（腎）、手腳冰涼、精力弱。

## 3. 命名慣例
1. L2：「业的X」佔多數（业的原理/业的复杂性/业障病），或「业与X」（业与结缘/业与加持），或「X的方法」（消业的方法）——章主題詞（业）領頭。
2. L3四型：(a)「X的Y」單軸（业的产生/加持的原理/报身结业缘）；(b)**斜槓並列「A/B/C」**＝收錄範圍清單（儿科/遗传病/皮肤病/头发、心/肺/脑/血管/中风/瘫痪、不顺/世间业/共业/行侠仗义）——任一命中即收；(c)「X及应对」＝現象＋對治都收（修行牵出业障及应对/非人干扰及应对/冤亲债主及应对/疾病的原因及应对）；(d)主語開頭定身分（凡夫多结善缘/再来人慎重结缘/再来人消业/与TAI师父的缘）。
3. 括號補充＝手段清單：「修行善行消业(打坐磕头念经放生朝圣)」。
4. 「X与Y不同」型作辨異節（业缘与佛缘不同）；「消业/转业的逻辑与表现」用斜槓連近義語。
5. 語言：簡體、口語化、提問者視角（「与TAI师父的缘」非「师徒关系」）。

## 4. 判別實例（引自證據檔）
1. 「缘起尘微: 问题二、佛门有个著名公案，禅师说出家人不落因果，于是被罚变成了狐狸。假设他能及时忏悔……能否把变狐狸的果，拖延到成为阿罗汉之后再承受呢？」→**业的产生/作用范围**（果報能否延後的機理；雖提懺悔不落「忏悔与拜忏」）。
2. 「Lanlan岚: ……关于加持传递逻辑……①在轮回里②彼此之间相互参与③产生业……这才会成为彼此的众生么？」→**加持的传递**（傳遞條件；非「加持的原理」——問的是路徑條件）。
3. 「淡薄123: 1、小时候偷过别人东西，对此很悔恨，应该怎么做才能化解这些恶业。」→**凡夫消业**（個人舊業+求解；非「忏悔与拜忏」——未聚焦拜懺操作；非「逻辑与表现」——非抽象）。
4. 「hffhi: ……摆脱原生家庭，反抗克自己的父母后……打了父亲运气变好……打骂父母不是要下地狱的吗？怎么还会这样呢？」→**家人/感情/婚姻的业**（對象=父母、問業理矛盾；非12-家庭父母——有歸因問句）。
5. 「潮起又潮落: ……打坐打通中脉，进入初禅也不能避免癌症吗？……（禅师能看到自己和别人未来的命运）……临终他自己一直忏悔自己的口业和傲慢。」→**不敬/攻击正法/信受传播邪法**（複合題按主軸口業；已核對HTML原文與師答：答案主體是攻擊修行人的業）。
6. 「觉莲: ……孩子两三岁时半夜高烧，突然爆出惊恐尖厉大叫……口鼻中喷出一团棉花糖状白沫……这是发生了什么？夺舍吗？」→**冤亲债主及应对**（債主/附體框架；非「儿科」——雖對象是小兒）。
7. 「Zhiyu: 请问肺结节有办法调理治疗吗？能否通过打坐和练呼吸来调理？」→**心/肺/脑/血管**（錨定肺結節；療法含打坐不改變歸屬；非10）。
8. 「J丶: 最近有非常多障碍修行的事情……打坐先是膝盖痛……磕大头也开始膝盖响……念地藏经……脑海中有个声音总是说不对……」→**修行牵出业障及应对**（複合多症狀＋歸因「障碍修行」；不拆成10/09）。
9. 「果慧: 1、在其它平台别人说双盘疼痛是在消业，多熬一分钟就消一分业，请问是这样吗？」→**修行善行消业**（問消業真偽機理；非10-腿脚反應）。

## 5. 灰色地帶（無法從樣本確定）
1. **回向/代修類三不管地帶**：「替家人做功德治病」同時命中02-求愿、02-冤亲债主、06-功德回向。樣本傾向：求菩薩辦事→求愿；認定債主→冤親債主；問回向技術→06。但混合題的切分無樣本級保證。
2. **失眠頭痛四分**：02-精神类 vs 10-上身反应（打坐致失眠/頭痛）vs 09-磕头反应 vs 12-睡眠姿勢。判準「有無修行脈絡＋歸因問句」可分多數，但「精進就失眠」樣本歸02-修行牽出業障，純症狀無歸因時無法確定。
3. **拆分孤兒片段**：「阿难乎: 3.师父您还会生病什么的不？」落在眼耳鼻喉/牙，僅從該句無法推出部位——推測跟隨同訊息其他部分歸位。LLM對無錨點孤兒片段只能追同批片段或標「待人工」。
4. **疫苗/新冠**：02-免疫/傳染病 vs 10-伤病与修复-疫苗后遺症修复，同一事實兩面，僅能看主問動詞（治病vs修復練習），邊界題無法唯一確定。
5. **代孕**在02-家人/感情（生育），但「靈體何時入胎」知識面也屬04-中陰身/入胎；樣本未給出兩章收錄比例。
6. **重複提交**：「极乐清净」同文同asker兩則、「念佛方能消宿业/念佛方能消旧业」同文兩則（向佛求愿節）均原樣保留；感應節TOC計30則、證據檔標29則，差1或與重複認定有關——重複是否視為一則無法從樣本確定。
7. **02-业的复杂性 vs 12-红尘琐事**：同域界線靠歸因問句；混合題樣本偏歸02，但一致性未驗證（12的紅塵瑣事樣本不在本章證據內）。
8. **佛的業**（佛頭疼、佛族滅族）在02-业的产生；但「佛如何存在」類佛身問題在04-解脱后的境界——「佛的業」vs「佛的境界」切分僅有2則樣本支撐。

## 6. 給LLM的操作規則（可直接執行）
**預處理**
- R0 拆分識別：開頭為「N、/N./N:/一、二、/问题N：/提问N、/第N问:/• QN：」→原訊息被拆分。**剝離編號前綴**，按該片段自身內容分類；同批片段可落不同節。同則內多題未拆（如「第2112问+第2111问」同框）按合併主題分類。
- R1 歸因軸優先：含「是什么业/算不算业/怎么消/什么因果/是不是冤亲债主/是不是业障」歸因問句者，歸屬由**歸因主題**決定，不被表面開頭詞（疾病名、練習名）牽走。複合題按主軸（樣本顯示歸類貼合答案主題）。
- R2 主語定節：凡夫→凡夫消业/凡夫多结善缘；罗汉/菩萨/再来人→再来人消业/再来人慎重结缘；师徒互动→与TAI师父的缘；佛菩萨→加持/感应/业缘与佛缘不同。

**正規則（判入02）**
- P1 有業類歸因/求解且他章主軸不先佔→02，再按§2細分。
- P2 求菩薩辦世間事（考試/病癒/錢財/工作/婚姻/父母/懷孕）→02-向佛菩萨求愿的方法。
- P3 非人/債主對活人干擾討報→02-非人干扰或冤亲债主（討具體債→冤亲债主）。
- P4 具名疾病＋因果/佛法救治→02-业障病，按「主訴病痛部位」查分科表（歧義取提問者自點系統；兒童多發先天→儿科；債主附體討報→冤亲债主）。
