# 09磕大头 — 章級分類準則（供 LLM 對未分類答疑自動分類用）

依據：`wenda2_ebook/09.html`（73 則全文逐則讀畢）、`/tmp/wenda_analysis/evidence/ch09.md`（16 節抽樣）、全書主題樹 `/tmp/wenda_analysis/toc_ch01_12.md`。答問者：Taiguanglin 禪師（下稱師父）。

## 1. 章級定位

**一句話**：問句的主語是「磕大头／磕头／大礼拜／大磕头／磕长头／磕小头／大拜」這個動作——問它的目的、裝備、方法、時機、練時/練後身體反應、修復功效、消業功效——就收 09。其他修行（打坐、呼吸、念誦）只在與磕頭互動時順帶出現，歸屬仍以問句主語為準。

### 1.1 收什麼（正樣本）
- 為什麼要磕頭、能否用別的代替（跑步、爬樓梯、道家功法、瑜伽）→ 09-01
- 磕頭的場地物件（墊子護具、音頻音樂、對著佛像）→ 09-02
- 怎麼磕：姿勢數量、磕小頭、時機空調、老人小孩病人 → 09-03
- 磕頭時/後的身體反應（發熱、汗、涕、痰、頭痛、皮疹、關節痛響）→ 09-04
- 以磕頭為修復手段（脫髮、骨盆、富貴包、舊疾案例）→ 09-05
- 磕頭語境的消業、功德校量、替人受苦 → 09-06
- 師父本人為何還每天磕 700 個 → 09-01

### 1.2 不收什麼
- 打坐/雙盤本身（姿勢、反應、吉時、術後病後打坐、打坐修復）→ 10
- 腹式呼吸怎麼練（姿勢、時長、練成標準）→ 08
- 念誦經咒本身（方法、數量、感應、回向儀軌）→ 07
- 消業/業理的一般論述、多法並列的善行消業 → 02（磕頭語境例外 → 09-06）
- 功德/回向的一般方法與跨法校量 → 06
- 拜懺儀軌、一般佛像供養禮佛常識 → 02-04-04、12-02-04
- 治病養生、解夢、運動健身本身、紅塵瑣事 → 12

### 1.3 邊界判準（從樣本歸納）

**vs 02羯磨**（磕頭消業是雙章共同話題，最易混淆）
- 問句主語是磕頭：「大禮拜消業的原理」「磕 500 個抵幾部地藏經」「磕頭替父受苦」→ 09-06（威、偶米大、九月實證）。
- 問消業的一般方法/邏輯表現、懺悔法、隨順忍辱、冤親債主 → 02-04；把打坐磕頭念經放生朝聖**並列**談善行消業（磕頭只是清單之一）→ 02-04-03「修行善行消業(打坐磕头念经放生朝圣)」。
- 疾病的業理（業障病）→ 02-05；磕頭引發的身體反應 → 09-04。

**vs 06修福積功德**
- 「磕頭有多少功德/福德」以磕頭為主語 → 09-06。
- 福報功德定義、積福方法、放生、回向方法與優先級、跨方法功德校量 → 06。實證：偶米大「磕大頭 500 個≈好幾部《地藏經》消業？」含校量意涵仍留 09-06，因錨點是磕頭。

**vs 08腹式呼吸**
- 磕頭時上不來氣、氣短打嗝 → 09-04-01（梵摩尼、恒河沙丫實證）。
- 呼吸法本身（怎麼練、練成標準）→ 08。
- 慣例：師父常以「先把腹式呼吸練好」回答磕頭反應（三日空頭痛、千予千尋皮疹），問題仍留 09——**答案提到的法門不改變歸屬**。

**vs 10双盘**（最大鄰章，688 則）
- 反應歸屬看**引發動作**：「磕頭後膝蓋響」→ 09-04-03；「打坐時膝蓋痛」→ 10-02。師父答案常是「用打坐雙盤修復」，問題仍留 09。
- 「老人/小孩/病人練**磕頭**」→ 09-03-04；「術後病後**打坐**」→ 10-01-07。
- 「磕頭的吉時忌時/空調/經期」→ 09-03-03；「打坐的吉時忌時/避風」→ 10-01-04。
- 「磕頭能否修復 X」→ 09-05；「雙盤能否修復 X」→ 10-03。
- 混合句（恒河沙丫「同時打坐和磕頭，磕兩百就累」、Tai贤心8055「磕頭與打坐時間不匹配」）→ 看問句主語是哪個動作，此二例主語是磕頭 → 09-03-01。

**vs 07/12（次要）**：「磕頭時配什麼音頻/念什麼咒」裝備面 → 09-02-01；念咒本身 → 07。跑步/爬樓梯作為**替代話題** → 09-01；作為健身本身 → 12-02-03。

## 2. 逐節準則

（格式：收錄主題｜判別關鍵詞｜節間邊界｜易錯歸屬）

### 09-01 为什么要磕大头（6）
- 收：磕頭的目的/必要性/不可替代性；與跑步、爬樓梯、佛道家功法、瑜伽的替代比較；師父已四禪為何還磕；打坐前準備中磕頭的地位。
- 關鍵詞：为什么(要)磕、代替/替代/平替、跑步、爬楼梯、功法、每天还磕、有必要吗。
- 邊界：「磕頭消業嗎」→ 09-06；「為什麼一定要磕**大**頭（vs 小頭）」→ 本節。
- 易錯：藍蓮花「磕小头可以吗？为什么一定要磕大头？」→ 09-01（問大頭必要性），不是 09-03-02。

### 09-02 磕大头的装备（5）
#### 09-02-01 垫子/护具/音乐（1）
- 收：磕頭用的墊子、護具、音頻/音樂（配大悲咒節奏磕）。
- 關鍵詞：垫子、护具、音频、音乐、边听边磕。
- 易錯：提到「專用墊子」但問腹部疼/分次少量（哆啦爱梦的百宝箱）→ 09-03-01；「磕頭時觀想/念什麼」無音樂語境（定兴）→ 09-03-01。

#### 09-02-02 对著佛像（4）
- 收：磕頭要不要對佛像、掛哪尊（觀音/彌陀/西方三聖）、佛像多小可以、沒佛像只心念佛號行不行、觀想佛菩薩在面前、不知思念哪尊名號。
- 關鍵詞：佛像、挂(一)副/像、观音、阿弥陀佛、西方三圣、铜佛、小照片、观想、前面没有佛像。
- 邊界：一般供佛/禮佛常識 → 12-02-04；念佛號咒本身 → 07。
- 易錯：DD泰粉丝「前面没有佛像，只在心里念佛号，能消业吗？」→ 09-02-02（問點是佛像闕如），帶「消業」字樣仍不入 09-06。

### 09-03 磕大头的方法（29）
#### 09-03-01 姿势与数量（14）
- 收：標準動作（雙手撐地、翻掌、額頭著地、腳背、起身屈膝、頭在上、臀不撅）與姿勢認證請求；藏傳大禮拜異同；數量（合適個數、佛珠計數、加量、分次、體力上限、與打坐量匹配、體質能否大量磕）；胸口撞地會不會傷；磕頭＋呼吸＋念佛＋打坐的組合方式；宿舍空間限制的替代。
- 關鍵詞：姿势、动作、标准、膝盖(弯曲/绷直/受伤)、额头、多少个、计数、佛珠、700、108、分多次、撑不起来、大礼拜、磕长头、观想什么。
- 邊界：姿勢**已造成**疼痛 → 09-04-03；老人小孩病人的練習許可 → 09-03-04；純裝備 → 09-02-01。
- 易錯：老王「怎麼計數」在本節不在裝備節；定兴「磕頭時觀想什麼念什麼」也在本節（無佛像在前語境時）。

#### 09-03-02 磕小头（2）
- 收：一直磕小頭行不行、平地磕小頭、磕小頭姿勢（臀貼腳跟、胸貼膝）、頭低於身的副作用。
- 關鍵詞：磕小头、小头、平地、头低于身体、副作用。
- 易錯：問「為什麼要磕(大)頭」→ 09-01；問小頭**可行性/做法** → 本節（念佛方能消宿业「4、磕头一直磕小头可以吗？」）。

#### 09-03-03 吉时忌时/空调（8）
- 收：何時磕（早晚、飯後、凌晨 1–5 點、晚上與中醫陰陽說）；季節（冬至–立春主藏不宜大汗）；經期暫停及以散步出汗代替；天熱開空調/不對冷風；連續磕 vs 分上下午。
- 關鍵詞：什么时候、早起、饭后、凌晨、晚上、冬至、立春、月经、空调、冷风、连续/分开。
- 邊界：**條件/時機**類 → 本節；出汗的**效果/反應**（排毒機制、傷陰、虛弱）→ 09-04-01。打坐吉時 → 10-01-04。
- 易錯：果慧「經期 7 天不能磕、散步出汗算排毒嗎」→ 本節（時機＋替代），不是 09-04-01。

#### 09-03-04 老人/小孩/病人练习（5）
- 收：小孩幾歲磕/磕多少（7 歲 108 個）；老人（60 多歲高血壓肥胖、51 歲初學）能否練、堅持不了怎麼辦；病人（氣血虧虛、靜脈血栓）能否練；家屬代問。
- 關鍵詞：小男孩、七周岁、老妈、六十多岁、五十一岁、高血压、肥胖、气血亏虚、静脉曲张、血栓、身体状况不好、信仰基督。
- 邊界：+打坐 → 10-01-07；一般修行功課建議 → 12-02-01；「病人怎麼**調整數量**」→ 09-03-01（哆啦爱梦實例）。
- 易錯：判準是「能不能練」vs「怎麼調量」；問許可 → 本節。

### 09-04 身体的反应（24）
#### 09-04-01 胸口不适/流涕/出汗（11）
- 收：磕頭中/後全身發熱發燙、流清涕、吐黏稠泡沫痰、咳白痰、放屁、大汗濕透/傷陰、出汗後累虛沒精神、氣色變好、鎖骨下方疼、呼吸困難/上不來氣/氣短/打嗝；伴隨主症的臉上小痘、膀胱/尿頻修復問。
- 關鍵詞：发烫、火炉、流(清)鼻涕、痰、咳嗽、放屁、出汗、湿透、大汗伤阴、虚弱、气色、呼吸困难、上不来气、气短、打嗝、锁骨、排毒。
- 邊界：頭痛/血壓/失眠 → 09-04-02；四肢關節腰腹皮疹 → 09-04-03；練呼吸本身 → 08。
- 易錯：恒河沙丫「磕頭時呼吸沒對嗎？」→ 本節（磕頭語境），不去 08。

#### 09-04-02 头痛/血冲顶/血压低/失眠（3）
- 收：磕頭時炸裂樣頭痛、血沖頂、血壓很低（42/76）、磕頭當晚失眠。
- 關鍵詞：头痛、炸裂、血冲顶、血压低、睡不著、失眠。
- 邊界：打坐的頭痛失眠 → 10-02-03；疾病性失眠頭痛 → 02-05-09。
- 易錯：心梅血壓低伴關節咔聲仍在本節——按主症（頭部/血壓）歸。

#### 09-04-03 皮疹/四肢痛/响/腰腹（10）
- 收：磕頭後紅色丘疹/痱子/臉腫癢；膝蓋作響、全身關節咔聲；胳膊腿疼；膝蓋痛/不舒服/有小窩；手腕疼；雙膝突然一彎抖動；小腹用力疼；手腕腰疼加劇；多症狀合併（含痔瘡脫出、護膝）。
- 關鍵詞：丘疹、痱子、痒、关节(咔/响)、膝盖(疼/作响)、手腕、胳膊、腿、小腹、腰、痔。
- 邊界：同類症狀由**打坐**引發 → 10-02；問「怎麼修復」仍留本節（Susan、海莲、链接爱——答案說用打坐修復不改歸屬）；以磕頭**主動求治**舊疾 → 09-05。
- 易錯：臉部皮疹為主症 → 本節（千予千寻）；臉上小痘只是咳痰伴症 → 09-04-01（恒河沙丫）。

### 09-05 修复身体（5）
- 收：以磕頭為修復/治療手段——脫髮白髮、骨盆傾斜/頸椎/體態不對稱、富貴包（含女兒能否磕）、韓國女孩磕頭治小兒麻痺案例、「磕頭多久上癮」（效果/習慣面，源分類如此）。
- 關鍵詞：修复、治疗、缓解、恢复、脱发、白发、骨盆、颈椎、体态、富贵包、大椎、恢复健康、上瘾。
- 邊界：打坐修復 → 10-03；磕頭引發的疼痛（反應）→ 09-04-03。
- 易錯：恒河沙丫「膀胱問題磕頭能修嗎」落在 09-04-01（源分類不一致，見灰色地帶#2）。

### 09-06 消业（4）
- 收：磕頭消業功效與校量（vs《地藏經》）；大禮拜消業原理（勞身吃苦提前受報、加持、我慢消失）；磕頭懺悔消業體悟；磕頭替人受苦/幫人治病（發願回向）。
- 關鍵詞：消业、原理、功德、回向、忏悔、发愿、替(他)承受、业报、加持。

## 3. 命名慣例
- 章名＝修行動作名（「磕大头」），簡體、無空格、無編號。
- L2＝修行生命週期序：目的(为什么)→装备→方法→身体的反应→修复身体→消业；與 10双盘 同構（修習→反應→修復→更久→通脈），可跨章對齊。
- L3＝關鍵詞清單：「/」並列症狀或物件（垫子/护具/音乐、胸口不适/流涕/出汗、皮疹/四肢痛/响/腰腹）；「与」連組合（姿势与数量）；人群斜杠列舉（老人/小孩/病人练习）。
- 固定詞組跨章複用：「吉时忌时」（09-03-03 ↔ 10 打坐吉時）、「身体的反应」（09-04 ↔ 10-02）——同名 L3 在不同章按引發動作區分。
- 源檔以簡體為主但混用繁體字（節名「对**著**佛像」用繁「著」）——比對時簡繁兩種寫法都要認。
- L3 名稱是提問者視角的症狀群，不是醫學分類；新症狀進來按「部位/現象」增補斜杠詞，不另立新節。

## 4. 判別實例（問題開頭片段，引自證據檔/原文）
1. 「师父，磕小头可以吗？为什么一定要磕大头？」→ 09-01：問大頭必要性，非小頭做法。
2. 「1、大拜磕头，前面没有佛像，只在心里念佛号，能消业吗？」→ 09-02-02：問點是佛像闕如；「消業」字樣不觸發 09-06。
3. 「2、我磕大头的时候头特别痛，像炸裂一样的痛……这种头痛是啥原因啊？」→ 09-04-02：磕頭引發＋頭部主症；主語換「打坐」則 → 10-02。
4. 「1、我的腿有静脉曲张……有静脉血栓可以磕大头吗？」→ 09-03-04：病人＋磕頭；若問「術後能否打坐」→ 10-01-07。
5. 「2、脱发和白发的问题，是不是可以通过大磕头来缓解？」→ 09-05：磕頭為修復工具。
6. 「师父好！1、最难坚持的就是磕大头，有人说一天磕大头500个，相当于读了好几部《地藏经》消业？」→ 09-06：磕頭語境消業校量；多善行並列的總覽式問題 → 02-04-03。
7. 「4、磕头一直磕小头可以吗？」→ 09-03-02：小頭可行性；與例 1 對照見「問理由 vs 問做法」。

4. **病人 vs 數量**：哆啦爱梦（萎縮性胃炎＋分次少量）→ 09-03-01；容（氣血虧虛能否繼續）→ 09-03-04。判準：問「能不能練」→ 03-04；問「怎麼調量」→ 03-01。
5. **出汗雙棲**：果慧（經期/散步替代）→ 09-03-03；呆瓜（磕頭汗 vs 天熱汗排毒）→ 09-04-01。判準：條件時機 → 03-03；出汗現象與效果 → 04-01。
6. **臉痘歸屬**：皮疹為主症 → 09-04-03；咳痰伴症的小痘 → 09-04-01。
7. **磕頭＋打坐混合句**：本章四例（Tai贤心8055、恒河沙丫×2、钟锦）全留 09-03-01——問句主語是磕頭。主語反轉的樣本未見，建議仍按引發動作歸 09。
8. **上癮問題**：「磕頭多久上癮」落在 09-05，語義更像效果/習慣面——源分類如此，LLM 照抄，勿自行改到 09-01。
9. **替人治病/回向**：九月「磕大頭幫他人治病」→ 09-06，可辯 06-05 功德回向；錨點是磕頭故 09 優先。
10. **消業字樣誤導**：多則問題以「消業」開場（海莲、DD泰粉丝、千予千寻），實際問點各為出汗/佛像/皮疹——以實際問句為準。

## 6. 給 LLM 的操作規則

**正規則（依序執行）**
- R1 命中觸發詞（磕大头/磕头/大礼拜/大磕头/磕长头/磕小头/大拜/拜佛〔＝磕頭動作〕）且該詞是問句主題 → 進 09 候選。
- R2 先判「反應 vs 方法」：症狀發生在磕頭時/後 → 09-04；否則續 R3–R7。
- R3 問目的/必要性/替代比較 → 09-01。
- R4 問場地物件：音頻音樂墊子護具 → 09-02-01；佛像設置/觀想佛在面前 → 09-02-02。
- R5 問怎麼做/多少/何時/誰能做 → 09-03：動作與數量、計數、組合 → 03-01；小頭 → 03-02；時機/空調/經期/季節 → 03-03；老人小孩病人許可 → 03-04。
- R6 反應按部位定 L3：頭痛/血壓/失眠 → 04-02；四肢/關節/腰腹/皮疹 → 04-03；其餘（汗涕痰熱呼吸胸鎖骨）→ 04-01。
- R7 主動求「磕頭治 X」→ 09-05；磕頭語境消業/功德/替人受苦 → 09-06。
- R8 編號子問題逐條拆分，各自按 R1–R7 歸屬（可跨節、可跨章）。
- R9 問句前的寒暄/經歷敘述（素食、斷淫、學佛緣起、感恩）不參與判歸（簡為上乘實例）。
- R10 答案提到的法門（「先練腹式呼吸」「用打坐修復」「做功德求加持」）不改變問題歸屬。

**負規則**
- N1 只講打坐/雙盤、未提磕頭 → 10；只講呼吸練習 → 08。
- N2 症狀主語是打坐 → 10-02，即使該人平時也磕頭。
- N3 拜懺儀軌、《礼佛大忏悔文》→ 02-04-04、07；一般供佛/佛像常識 → 12-02-04。
- N4 念佛號/念咒的方法數量感應 → 07；只有「磕頭配什麼音頻」→ 09-02-01。
- N5 消業/業理/冤親債主/業障病的一般論述 → 02（磕頭為主語才進 09-06）。
- N6 功德回向一般方法、福報定義、跨法校量 → 06。
- N7 治病養生、解夢、運動健身本身、紅塵事 → 12。
- N8 「哪種善行消業快」式多法比較 → 02-04-03；只比磕頭與另一法 → 09-06。
- N9 出現「消業」「功德」字樣但問點是姿勢/出汗/佛像 → 不入 09-06（見實例 2、灰色#10）。
- N10 家人信仰/兒童教育議題，只要問「他能否磕頭/磕多少」→ 09-03-04。

## 7. 拆分觀察

**編號前綴統計（73 則）**

| 類型 | 則數 | 佔比 |
|---|---|---|
| 阿拉伯數字前綴（N、／N.） | 30 | 41.1% |
| 中文數字前綴（问题一、／第一个问题:／第二、） | 3 | 4.1% |
| 編號只在訊息中後段（多子題同則保留） | 6 | 8.2% |
| 完全無編號 | 34 | 46.6% |

- 前綴編號合計 33/73（45.2%）；分布：「1、」14、「2、/2.」14、「3、」1、「4、」1、中文 3。
- 「2、」與「2.」共 14 則為最大宗 → 這些原訊息的「1、」幾乎都落在其他章；「3、」「4、」開頭者前導子題全不在本章。
- 各節前綴率：09-03-04 最高（4/5＝80%），其次 09-03-03（5/8）、09-05（3/5）、09-04-01（6/11）、09-01（3/6)；最低 09-02-02（1/4）、09-06（1/4）。

**同發送者同時間戳的拆分對（章內可直接驗證）**
1. 恒河沙丫 2025-01-13：「2、」（咳痰臉痘）＋「3、」（尿頻膀胱）同入 09-04-01；其「1、」不在本章。
2. 恒河沙丫 2025-02-12 18:49：「第一、」→ 09-05（磕頭上癮），「第二、」→ 09-04-01（氣短打嗝）——同一訊息拆到兩個 L2。
3. 逐月A 2025-05-15 17:12：「1、」→ 09-05（韓國女孩案例），「2、」→ 09-04-01（全身發燙）。
4. 偶米大 2024-03-26 18:04：「1、」→ 09-06（消業校量），「2、」→ 09-03-03（冬天出汗）。
5. Neo4, 20-06-2024：「1、」→ 09-01（爬樓梯代替），「2、」→ 09-03-03（何時磕）。

**自稱多問題的訊息（6 則）**：全保留 3 則（喝啰怛那哆啰夜姿勢「请教如下。1、2、3、」、小銅佛「请教2个问题：1、2、」、千予千寻「麻烦有3个。1、2、3、」——子題同主題故不拆）；部分保留 3 則（Tai贤心8055「问题1、」、李磊「想问两个问题：1、」、恒河沙丫「有两个问题：第一、」——宣告的後續子題不在原處；恒河沙丫的「第二、」恰在本章另一節）。

**拆分碎片特徵（LLM 可執行）**
- 開頭直接是編號（「2、……」），無稱呼、無背景、無緣起敘述。
- 帶回指詞：「还有关于大礼拜」「之前问过Tai师，现在还是想问」「第二、」——指回原訊息前文。
- 同一提問者同日多則、編號不重排、保留原序號。
- 拆分粒度＝節的主題：子題同主題 → 同節保留；跨 L2 主題 → 拆到本章不同節；跨章主題（如打坐、念經）→ 拆到其他章。
- 操作建議：見「N、」開頭且 N＞1，預設它是殘件，只按該子題自身內容歸屬；可用「提問者＋日期」檢索兄弟件佐證。
