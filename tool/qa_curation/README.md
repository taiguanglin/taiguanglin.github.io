# qa_curation — 問答錄2 拆分與分類準則（LLM 作業 SoT）

把《坐禪之問答錄2》**未分類**的第 13–21 章（月度答疑）交給 LLM 做
「問題拆分＋12 章主題分類」時，這個目錄是準則的單一真相來源。

## 檔案

| 檔 | 用途 |
|---|---|
| `wenda2_split_classify_criteria.md` | **主準則**：十條鐵律、1–12 章結構事實、拆分準則（實證統計）、分類總綱（跨章判準/多義詞/命名慣例）、13–21 輸入面、作業流程＋輸出 schema、12 章完整主題樹附錄 |
| `chapters/ch01.md` … `ch12.md` | **逐章準則**：章級定位、逐節收錄範圍與關鍵詞、跨章邊界、判別實例、灰色地帶、正/負規則（R/N）、拆分觀察 |
| `chapter_split_design.md` | **拆頁設計筆記**：分類併入後 1–12 章單檔膨脹的解法——章頁降級為章目錄＋L2 節子頁（命名 `NNsXX.html`）、歷史深鏈轉址表、受影響模組、門檻制、驗收清單。實作落 `tool/word2ebook/`。 |
| `SKILL.md` | skill 檔：給 LLM session 載入的操作版（含 frontmatter） |

## 準則怎麼來的

2026-10 對 `wenda2_ebook/01.html`–`12.html`（5,789 則、545 節）逐一實證檢驗：
結構統計全量掃描（拆分率、同鍵多則 1,266 組、節內時間排序 100% 驗證）、
逐章內容取樣歸納（12 個平行檢驗）、跨章邊界以 grep 對鄰章實際歸屬交叉驗證；
人工分類母體為 `問答錄2/1_坐禅问答汇总 分类精选工作表 20251219v2.xlsx`
「答疑汇总」A–D 欄（目录1–4）。

## 使用方式

1. LLM session 載入 `SKILL.md`（或直接讀主準則＋目標章的 `chapters/chNN.md`）。
2. 輸入＝13–21 章的問答串（HTML 或抽取後的 JSONL）。
3. 輸出＝主準則 §6.3 的 JSONL（每子問題一行，含 `section_path` 與信心標記）。
4. 按 §6.4 驗收清單自查；`needs_review` 條目交人工複查。
5. ⚠️ 分類產出若要回建電子書：先併入分類 Word 母檔再 `gen_all.py`；播放鈕
   對位會因 `question_id` 改變而需重跑音檔管線（主準則 §6.5）。

## 邊界聲明

- 本目錄只放**準則文件**，不放分類產出資料（產出建議放 gitignored `build/`）。
- xlsx 另有「新版目录」（义理/修心…I–IV 級）的重組嘗試（2025-09 草稿、僅
  26 則精選標記）——**非本準則的分類目標**；本準則對齊已發布的 12 章體系。
