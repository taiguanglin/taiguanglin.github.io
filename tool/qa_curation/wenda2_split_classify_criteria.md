## 0. 十條鐵律（LLM 必先讀）

1. **分類目標＝既有 12 章體系**（章 h1 → L2 節 → L3 小節 → L4 細節，即 xlsx 目录1–4）。
   不得自創章；新主題先找最接近的既有節，必要時在輸出中「建議新節」而非直接使用。
2. **原子單位**＝一個編號子問題（或一個獨立主題句）＋師父回答中對應的段落。
   一則條目只講一件事。1–12 章實測：含 ≥2 個編號子問題仍不拆的條目趨近於 0
   （嚴格掃描僅 115 則例外＝相鄰子問題屬同一小節時可保持合併）。
3. **同一訊息拆出的子問題各自獨立分類**，可散落不同節、甚至不同章
   （實測 1,266 組「同提問人＋同時間」訊息被拆成 2–22 則，跨章分布）。
4. **原文不可改寫**：子問題編號（「2、」「问题3：」「第N问」「①」）、問候語
   （「Tai师父好！」跟著第一個子問題）、時間戳格式（`2024-7-16`、`20-06-2024`、
   `2024/11/15` 等原文格式不一，一律保留原樣）。
5. **節內排序＝時間先後**（實測 545/545 個節次 100% 依答疑日期升冪，跨 2024→2025）。
6. **分類看「問句主軸＋師父答案主軸」，不看開頭情境、不看字面關鍵詞**。
   例：「夢見亡父」開頭、實問「為父親念一年地藏經」→ 07 初學節，非 04/12 夢境。
7. **每則輸出**：`章-L2-L3(-L4)`＋中文節名＋信心分數＋一行依據；灰色地帶必須附
   第二候選節；無把握時誠實降信心，不硬猜。
8. **跨章優先序**：01–11 各有專題域，**12「佛门修行」是 fallback**——先排除專章
   才落 12；反過來，專章訊號（打坐/業/往生/戒/經咒/發願/功德/呼吸/磕頭/禪定）
   命中時優先歸專章。
9. **重複不刪**：同文同提問人的重複提交在 1–12 章原樣保留於同節（實測僅 9 則
   id 後綴重複）。13–21 章分類時發現重複：各自分類＋標記 `duplicate_of`。
10. **音檔斷鏈警示**：`question_id`＝MD5(提問人+時間+內容前50字)。拆分或改寫
    問題文字會改變 id，使 `audio_map/*.json`（站台根目錄；月度分類條目播放鈕）與
    `audio_map2/*.json`（1–12 章）失去鍵連。分類產出若要回建電子書，音檔對位
    必須另行重跑管線（tool/pdf_audio_map / word_audio_map2），不屬本準則範圍。

## 2. 問題拆分準則（1–12 章實證）

### 2.1 拆分單位定義

**一則條目** ＝ `提問人＋時間戳＋一個子問題` ＋ `Taiguanglin 針對該子問題的回答段落`。
- 提問人＝原訊息作者名（含「贴吧用户_XXX」匿名形態，保留原樣）。
- 時間戳＝原訊息頭的時間（格式不統一，**逐字保留**：`2024-03-01 13:18`、
  `2024-7-16`、`20-06-2024`、`2024/11/15` 都存在於 1–12 章）。
- 問題文字＝該子問題的原文（含編號前綴、含專有名詞簡體原文）。
- 答案文字＝師父回答中對應該子問題的段落（可能從「还有…」這種承接句開始，
  例：hffhi 第 3 問拆出條目的答案開頭即「还有出轨会下地狱吗？」）。

### 2.2 拆分觸發（何時一變多）

| 觸發型 | 例子（實測） | 處理 |
|---|---|---|
| 阿拉伯數字編號 | 「1、」「2、」「1.」「2.」 | 按編號切開；編號保留在各自條目 |
| 「问题N：」 | 「问题1：如来藏和阿赖耶识…」 | 同上 |
| 「第N问/第N个问题」 | 「第7问:」「第8.1问:」「第2106问:」 | 同上；自編小數編號也照切 |
| 中文數字 | 「一、」「二、」 | 同上 |
| 圓圈/括號 | 「①」「(1)」「（二）」 | 同上 |
| 無編號多主題 | 薛祖宜一則含「念楞嚴咒見影像」＋「記憶與妄想關係」 | 按主題邊界切；答案按對應段切 |
| 續問標記 | 「接上」「另外我想再问」「还有」 | 視為新子問題，獨立成則 |

**不拆**的情況：
- 相鄰子問題屬同一小節且語意連貫（115 則 kept-together 案例的共同特徵）——
  例：「第9问…第10问…」同講「定中念經＝滅文字妄想的執著」。
- 師父把多個子問題**合併回答**、無法乾淨切分時，保持一則＋標記 `merged_answer`。
- 提問人自己分多次發送的同日連問（時間戳不同）＝本來就是多則，無需拆。

### 2.3 拆分操作規則

1. **先切問題、再對位答案**：師父通常逐題作答（口頭慣例以提問人名起頭、
   重述該子問題），以答案的「重述句」為切割錨點。
2. **問候語歸第一則**：「Tai师父好！问题1：…」的問候語跟第 1 個子問題走。
3. **編號原文保留**：不重新編號、不改寫「问题1」→「1、」。
4. **缺主語片段**：拆分片段常以「2、可以盘腿坐著练习吗？」形態出現——
   從母訊息繼承主題語境後歸類，但條目文字仍保持原樣。
5. **黏連殘留**：若拆分時誤把兩個子問題黏在一則（06 章實測一例：楞嚴咒延壽
   ＋家門口施食黏成一則），分類以「實際被回答的子問題」為準。
6. **孤兒片段**：無法判斷主題的拆分殘片（如「3.师父您还会生病什么的不？」）——
   追同批兄弟片段的歸位；仍無法判斷→標 `待人工`，勿硬分。

### 2.4 拆分後分發

- 每個子問題**獨立分類**（不同章/節是正常且正確的行為，勿加「同訊息同節」約束）。
- 同批子問題在同章時，常落不同節（例：「念佛方能消宿业」一則三問分落 07 的
  三個 L3；「三日空」80 則散布全部 12 章）。
- 同一提問人在 1–12 章中反覆出現的長期系列（掌南飛、果慧、灵光台…），
  各則按內容獨立歸位，**不得按編號整批同歸**。

### 2.5 重複、殘缺與排除

- **重複**：同文同提問人的重複提交→原樣保留、各自分類（1–12 章僅 9 則 id 去重
  後綴案例）。13–21 章處理時另以 `duplicate_of` 標記供人工決定。
- **殘缺**：問題佔位「问题缺失」、有問無答→標記 skip，不硬分（04 章實測各 1/3 則）。
- **精選排除**（僅供「精選」場景，全量分類不適用）：xlsx「精选标准（草稿）」
  工作表明載——「师父回答说以后再讲」的問答可不選。13–21 章實測僅 2 則
  答曰「以後再講」，全量分類仍收錄，另加 `deferred_answer: true` 標記。

## 3. 分類準則總綱（跨章原則）

### 3.1 章級判準的通用句型

判斷一章的歸屬，先讀完整訊息，找「問句真正要答案的對象」（疑問句主賓語），
再看師父答案的主軸印證。各章一句話錨點：

- **01**：問「心是什麼、裝了什麼、怎麼滅」——自性/八識/妄想/分別/執著/習氣情緒
  的認識與對治。公理層，與身體、世界、事相無關。
- **02**：問「業怎麼產生/怎麼消/顯現成什麼」——含向佛菩薩求世間願、非人/債主
  干擾、具名疾病的因果救治（業障病按主訴部位分科）。
- **03**：問「願本身」——算不算、第幾級、怎麼發、發不出、退轉、發了會怎樣。
- **04**：問「世界觀事實」——世界/六道/佛菩薩體系是什麼、怎麼運作、死後去哪、
  如何往返；含往生極樂的信願行/品位/助念/接引。
- **05**：問「這條戒」——殺盜淫妄酒的定義邊界、果報、消此業、破戒標準；與
  一切「能不能吃/算不算犯戒」的飲食問題。
- **06**：問「功德福報這種通貨」——是什麼、值多少、怎麼賺、怎麼花（回向）、匯率。
- **07**：問「念誦這個行為」——怎麼念、念出什麼反應、為誰念、經書物件、
  指名經咒的深問（按經名/咒名 L4 歸位）。
- **08**：問「腹式呼吸練習」——獨立於打坐的日常身體訓練（站練為主）。
- **09**：問「磕大頭」——裝備/方法/反應/修復/磕頭語境的消業。
- **10**：問「跏趺坐的身體與練習」——姿勢/時間/環境/身體反應/傷病修復/經脈。
- **11**：問「心的修法與定中境界」——禪修法門（觀丹田/觀呼吸/念佛/觀佛/參思情）
  與禪定次第（欲界定/初禪/二禪）、習禪須知（幻覺/陰神/次第狀態）。
- **12**：其餘一切——修行要領/佛菩薩/法門/高僧/佛教百科/外道/修行與生活
  （紅塵瑣事/治病養生/夢境/靈異）/師父道場。**fallback 章優先序最低。**

### 3.3 節標題命名慣例（新增節時必守）

- **層級語體**：一律簡體、口語化、提問者視角；章名帶編號（「01自性与意识」）。
- **L2 構詞**：大域名 4–6 字（「业的原理」「修行要领」）；兩概念並列用「与」
  （「解脱与成佛」）；「X与Y」表關係（「业与结缘」）。
- **L3 構詞四型**：①「X的Y」屬性式（「加持的原理」）；②「A/B/C」斜線並列＝
  收錄範圍清單，任一命中即收（「儿科/遗传病/皮肤病/头发」）；③「X及应对」
  ＝現象＋對治雙收；④主語定身分（「再来人消业」「与TAI师父的缘」）。
- **L4 構詞**：最小切面，常用對立軸（环境vs众生、过程vs成败、条件vs时空）；
  經名/咒名直接用「/」串同組（「大悲咒/六字大明咒/白衣大士神咒」），
  單部經全名不縮寫；兜底節「其他X」。
- **括號補充**＝手段清單（「修行善行消业(打坐磕头念经放生朝圣)」）。
- 用「校量」不用「較量」；計數 `(N)` 是顯示層，不屬名稱。
- **新節門檻**：≥5 則同質新主題才建議新節；命名依上述構詞，勿造新格式。

### 3.4 分類程序（先後順序）

1. 剝離編號前綴與問候語，確定子問題文本（§2）。
2. 逐章跑**負規則**（各章檔案 N 條）：命中即轉出，防止字面誤導。
3. 跑**正規則**定章（3.1 句型＋各章 R 條）。
4. 章內逐層下探 L2→L3→L4，先看專節、再看兜底節。
5. 驗證：讀師父答案主軸，若與問題表面主題衝突，以「實際被回答的內容」為準。
6. 輸出節號＋節名＋信心＋依據；灰色地帶附第二候選（§6 schema）。

### 3.5 既有分類的真實噪音（容錯預期）

- 近同題異章存在（「发愿将功德回向往生是不是菩提心」實例落 06 而非 03）——
  歷史分類非 100% 一致。LLM 以判準為準，容忍少量不一致，不模仿噪音。
- TOC 計數與實際條目偶有 ±1 差（02 章感應節 30 vs 29），屬重複認定差異。
- 少數條目主題與所在節僅部分相關（拆分黏連殘留），分類時以內容為準更正。

## 6. LLM 作業流程與輸出規範

### 6.1 輸入

從 `wenda2_ebook/NN.html`（13≤NN≤21）或月度 PDF 原文抽取的問答串，逐則含：
`來源章(13–21)`、`h2 日期＋來源`、`question_id`（若有）、`提問人`、`時間戳`、
`問題文字`（含 `<br/>` 換行）、`答案文字`、`has_image`（若有）。

### 6.2 處理步驟（每則）

1. **拆分判定**：按 §2.2 觸發表掃描問題文字；一變多時同步切答案（§2.3）。
2. **逐子問題分類**：§3.4 程序（負規則→正規則→章內下探→答案印證）。
3. **信心標記**：`high`（規則直接命中）／`medium`（單一灰色地帶）／
   `low`（多候選、無錨點孤兒片段、源檔殘缺）。
4. **不確定即標記**：低信心條目列人工複查清單，禁止為湊數硬分。

### 6.3 輸出 schema（JSONL，每子問題一行）

```json
{
  "source_chapter": 13, "source_section": "2025年6月9日 贴吧",
  "source_question_id": "question-f77cdc5dd1b4",
  "questioner": "宁缺岁岁平安", "time": "2025-05-18 08:34",
  "split_from": null,
  "question_text": "…原樣保留…",
  "answer_text": "…對應段落原樣保留…",
  "has_image": false,
  "chapter": 4, "l2": "极乐世界", "l3": "往生极乐", "l4": "往生信愿行",
  "section_path": "04-07-04-02",
  "confidence": "high",
  "rule_hit": "R6 極樂優先；問句=往生把握",
  "runner_up": null,
  "deferred_answer": false,
  "duplicate_of": null,
  "needs_review": false
}
```

欄位規則：
- `split_from`：拆分來源母條目的 `source_question_id`（未拆為 null）。
- `section_path`：`章-L2-L3(-L4)` 編號（L2/L3/L4 序號＝該章目錄中的第幾個）。
- `runner_up`：灰色地帶第二候選 `section_path`。
- 拆分出的多行共享同一 `source_question_id` 與 `split_from`。
- `needs_review: true`＝low confidence 或孤兒片段或源檔殘缺。

### 6.4 驗收清單（每批次跑完自查）

- [ ] 條目守恆：輸出行數 ＝ 輸入則數 ＋ 拆分增量（無丟失、無合併）。
- [ ] 每章抽 10 則（high/medium/low 各取）人工複核，命中節名與節號一致。
- [ ] `chapter=12` 的比例合理（fallback 過高＝負規則漏跑；過低＝硬塞專章）。
- [ ] 所有 `needs_review` 條目已列清單；`confidence=low` 佔比 ＜ 15%。
- [ ] 拆分案例（`split_from` 非空）答案段與問題段對位無重疊、無遺漏。
- [ ] 節內排序：按 `time` 日期升冪檢查輸出順序（§0.5）。

### 6.5 回建電子書的路徑（供參考，非本準則範圍）

分類結果最終要併入「已分類 Word 母檔」（目錄1–4 標題結構）再跑
`tool/word2ebook/gen_all.py`；播放鈕注入依賴 `question_id`——拆分/改寫過的
條目 id 會變，需重跑 `tool/pdf_audio_map/`（13–21 章來源）對位，
並以 `tool/word_audio_map2/link_chapters.py` 重寫章節對應。⚠️ 有
`meta.lastPlayed` 的已校對段任何腳本都不可改動。
