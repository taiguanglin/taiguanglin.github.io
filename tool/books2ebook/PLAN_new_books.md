## 產出

1. **books/ 新增 PDF**（最終下載檔，全部只提供 PDF，不提供 docx）：
   - `books/` 沿用既有命名風格，編號接續：`06 …四十二章經….pdf`、`07 …楞伽經….pdf`、`08 …六祖壇經….pdf`、`09 …楞嚴經（未完）….pdf`；「感恩与讲经」無編號，命名與插旗位置另行決定（建議仍以「03a」類命名或獨立檔名）。
   - **六祖壇經**：兩個 PDF 合併為一份，檔首加入 TOC，頁碼必須正確對應合併後實際頁面（用 PyMuPDF：記錄第一冊頁數作為第二冊各講的頁碼偏移，再插入帶連結跳轉的 TOC 頁）。
   - **楞嚴經**：多個 docx 先轉 PDF（macOS 用 LibreOffice headless `--convert-to pdf`；若無 LibreOffice 則用 pandoc/docx2pdf，需先確認工具存在），按 (N) 順序合併為一份，檔首 TOC 同樣要頁碼正確＋可點擊跳轉。
   - 感恩/四十二章/楞伽已是單一 PDF：仍要在檔首補上正確 TOC（若原檔已有可用書籤可直接採用，否則依講次分節產生）。
2. **audio/ 新增子資料夾**（如 `audio/jiangjing/` 或按書分資料夾，自選但全站一致）：
   - mp3 → opus，規格對齊既有答疑檔：`libopus`、單聲道、48 kHz，bitrate 約 16k（既有檔：6313s / 13.6MB ≈ 17kbps）。驗收標準：**同時長的音檔，輸出大小與既有答疑 opus 相當（誤差 < 30%）**。
   - 檔名規範化，含日期＋書名＋講次（沿用既有 `2024年11月11日Tai師父答疑.opus` 風格，繁體）。
3. **ebook/ 重建**（改 `tool/books2ebook/`，不可手改 `ebook/`）：
   - 在 `config.py` 註冊五本新書（含來源 PDF、標題、講次→opus 檔的映射），調整顯示順序為 01,02,03,感恩与讲经,04,05,06,07,08,09。
   - 每本新增一個 parser（仿 `parsers.py` 既有寫法；楞嚴經/壇經吃「含 TOC 的合併 PDF」，其餘吃單一 PDF）。
   - **播放按鈕**：五本新书每個章節（講次 N）注入對應 opus 的播放按鈕，機制參考 `wenda2_ebook` 的 audio_map 注入方式——建立 `講次 N → /audio/.../N.opus` 映射表（資料檔放 `tool/books2ebook/data/`），build 時由 html_generator 於章節標題處輸出播放按鈕，勿事後手改 HTML。
   - 重建：`/usr/bin/python3 tool/books2ebook/gen_all.py`（或 main.py）。
4. **ebook/ 首頁（`index.html` / `index_trad.html`）下方**：新增「新書 PDF 下載」連結區，四(五)份產出 PDF 全部提供下載（HTML 由產生器輸出，連結指向 `../books/<檔名>.pdf`，參考既有頁面相對連結寫法）。只放 PDF，不放 word/docx。

## 執行步驟順序

1. 檢查工具：`ffmpeg`（含 libopus）、`LibreOffice` 或替代 docx→pdf 工具、系统 Python 有 `pymupdf`。
2. 音檔轉換：ffmpeg 批次 mp3→opus（48k/單聲道/16k bitrate），放入 `audio/<新子資料夾>/`；抽樣比對時長與檔案大小比例是否達標。
3. 產生 books/ 新 PDF：壇經 PDF 合併＋TOC；楞嚴經 docx→pdf→合併＋TOC；其餘三本補 TOC。逐一開啟驗證 TOC 頁碼與跳轉正確。
4. 建 `講次→opus` 映射資料檔；逐書確認每個音檔都有對應章節（注意缺講/編號跳號，例如壇經 19–27 缺哪些日期、楞嚴經 1–21 是否連續）。
5. 修改 `tool/books2ebook/`：config 註冊、新增 parsers、播放按鈕注入、首頁下載連結區。
6. 重建 ebook：`/usr/bin/python3 tool/books2ebook/gen_all.py`。
7. 驗收：
   - ebook 首頁書序正確（01–09＋感恩与讲经位置正確）。
   - 五本新書各章節有播放按鈕且 source 指向存在的 opus。
   - 簡/繁兩版均正常、搜尋索引重建成功。
   - 首頁下方 PDF 下載連結可達 `books/` 新檔，且無 docx 連結。
8. 注意：`audio` 是 symlink 且 gitignore，不要 commit 音檔；PDF 加入 git。

## 風險／注意

- 講次編號可能缺號或日期與編號不連續，映射表以人工核對後的資料檔為準。
- LibreOffice docx→pdf 可能版面跑掉；合併後隨機抽頁檢查。
- TOC 頁插入會讓原頁碼整體偏移，頁碼計算必須用「插入 TOC 後」的最終頁序。
