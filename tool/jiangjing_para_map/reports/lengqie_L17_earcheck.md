## 五、⚠ 本輪的一次事故與修復（記錄以免重犯）

**用 `git checkout audio_map3/lengqie.json` 測試裁決表「單次套用可重現」時，把整個 SoT
檔案還原到 HEAD，連帶沖掉了先前 L13／L14／L16 已套用的修正**（L15 因當時已在 HEAD 中而倖免）。
發現後以四張裁決表（`lengqie_L13_adjudication_r3`／`lengqie_L14_adjudication_r3`／
`lengqie_L15_adjudication_r4`／`lengqie_L16_adjudication_r2`）全部重套修復，並逐段驗值。

**規則（已寫入 AGENTS）**：
1. **永不對整個 `<series>.json` 下 `git checkout`**。要驗可重現性，就把目前的檔案
   `cp` 到 `/tmp`，`milli_refine` 是 **idempotent**（第二次跑 = 0 段變更）——
   直接在同一份工作樹上跑第二次即可證明可重現，根本不需要還原 git。
2. 每次套用後的驗證**必須涵蓋「先前所有講次」**，不能只看目標講次：
   ```python
   for L in all_lectures:
       assert json.dumps(prev[L]) == json.dumps(cur[L])   # 非目標講次 byte-identical
   ```
