## 三、本輪新增的工具能力：`clip_probe.py --times`

切片複驗時發現 `--chars` 只印「每行首字時間 + 一行字」，**無法取得每個字的精確秒數**——
這正是 SKILL §10d 講的插值陷阱。已新增：

```bash
# 舊：只給行首時間，其餘字要靠反推（不可用來定段界）
clip_probe.py --series lengqie --lecture 20 --windows "784-796" --chars --width 14
# 新：逐字「字+精確秒數」（切片版 chars，定段界用這個）
clip_probe.py --series lengqie --lecture 20 --windows "784-796" --chars --times --width 30 --vad-ms 10000
```

**但切片字級時間必須先驗時基**（SKILL §6b）：拿兩個非掉字區與主 dump 逐字比對，
確認差 <1s 才能採信。L20 實測 900–912／1300–1312 兩區差 0.2–0.8s → 可信。
