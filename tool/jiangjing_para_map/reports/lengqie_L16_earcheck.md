## 三、本輪最大的一課：**不要用行內插值定段界**

`win.py` 印的是「每行第一字的時間 + 該行文字」，我最初用**行內等距插值**推算每字時間，
在行長不均時誤差可達 **2 秒**（L16 實測：[33] 的「隨」真實在 **454.65**，
我插值成 456.6 → 反而把段界改晚了 1.9s；[97] 的「好了」真實 **1930.52**，我插值成
1929.72 → 把一個本來精確的值改壞了）。

**規則：行內插值只用來定位「要看哪一段」，最終取值一律回到精確字元時間**：

```bash
tool/sense_voice/.venv/bin/python - <<'PY'
import sys; sys.path.insert(0,'audio_map3/skills/milli-align/scripts')
sys.path.insert(0,'tool/jiangjing_para_map')
from seq_align import load
lec, st, _ = load('lengqie', '16')
ts = [st.t_of(q) for q in range(len(st.norm))]
def qat(t):
    lo, hi, out = 0, len(ts), 0
    while lo < hi:
        mid = (lo + hi) // 2
        v = ts[mid]
        if v is None or v <= t: out = mid; lo = mid + 1
        elif v is None: lo = mid + 1
        else: hi = mid
    return out
lo, hi = 452.0, 460.0
print(" ".join(f"{st.norm[q]}{ts[q]:.2f}" for q in range(qat(lo), qat(hi)) if ts[q] is not None))
PY
```
