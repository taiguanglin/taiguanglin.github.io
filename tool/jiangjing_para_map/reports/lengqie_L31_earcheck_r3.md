## 3. 規則校準（golden 對照實驗）—— 為何採用「相鄰停頓 hosting」

以**人工 confirmed 的 golden 講次**（L21、L23）反測四種 hosting 規則（own_first 獨立以拼音命中估算，sim≥0.75）：

| 規則 | L21（n=41）median / ±0.3s | L23（n=48）median / ±0.3s |
|---|---|---|
| **A = 本輪採用**（相鄰停頓 hosting，無則取區間內最後停頓） | **0.861s / 46%** | **0.111s / 75%** |
| B = 物理靜音 hosting | 1.209s / 29% | 0.394s / 48% |
| C = 僅相鄰停頓 | 2.169s / 5% | 0.233s / 54% |
| D = 僅接觸型 | 2.169s / 2% | 0.387s / 38% |

**A 勝出**（L23 ±0.3s 達 75%，L21 46%）。→ 規則 A 即本輪引擎採用者。

### 3.1 邊界落點的物理特徵：與 golden **同型**

以 raw-PCM RMS（8kHz／20ms 窗／10ms hop）量測「邊界所在 0.4s 窗」的平均音量：

| 講次 | 落在物理靜音內的比例 | 邊界 mean-RMS p25 / p50 / p75 |
|---|---|---|
| golden L21 | 34/83 = **41%** | −65.3 / −45.5 / −28.9 dB |
| golden L23 | 29/88 = **33%** | −57.7 / −44.7 / −26.8 dB |
| **L31 r3（本輪）** | 33/80 = **41%** | **−57.8 / −45.5 / −34.0 dB** |

L31 r3 的邊界音量分佈與 golden **幾乎重合**（中位數 −45.5dB 完全相同）。
（另：改用「物理靜音 hosting」的變體會得到 59/80 = 74%、中位 −59.5dB，**偏離 golden 型態**，故不採。）

### 3.2 ASR dump 的「gap」與物理靜音不等價（重要）

實測 L31 有 **30/80** 個 hosting gap 在物理上**不是靜音**（`ffmpeg volumedetect` 量得 −9～−22dB＝有聲）。
**但這不是錯**：ASR 的字元 END 估計有誤差，dump 的「字尾→字首間隙」常涵蓋該字尾音的拖長。
判別依據是 **golden 對照實驗**（§3 表格）：規則 A 在 golden 上表現最好，且 L31 r3 邊界的音量分佈與 golden 同型。
故 **維持規則 A，不改用物理靜音 hosting**。

### 3.3 metric 的「早」是本規則的固有特徵，不是缺陷

| 講次 | metric median | 早(<−0.3s) 比例 |
|---|---|---|
| golden L21 | −1.87s | 86% |
| golden L23 | −0.42s | 68% |
| **L31 r3（本輪）** | **−0.33s** | 55% |

停頓轉場制把邊界放在**停頓內**（而非首字 onset），故 metric 系統性顯示「早」。
**人工確認的 golden 講次同樣如此**（L21 早 86%）→ r3（早 55%、median −0.33s）比 r2（早 4%、median ±0.00s）**更接近 golden 的真實型態**。
（r2 的 76% 命中是**循環論證**：r2 直接把 start 設成 own_first onset，metric 自然對得上。）
