> Read this first for **repo-wide** structure and conventions.  
> Tool-specific details live next to each tool (e.g. `tool/word2ebook/AGENTS.md`).  
> Prefer updating this file (or a tool’s `AGENTS.md`) over adding `.cursor/rules/*.mdc`.

---

## What this repo is

Static **GitHub Pages** site for TaiGuangLin (`taiguanglin.info` via `CNAME`).  
Deploy = push to `main` (no CI build step). Site chrome for marketing pages is Traditional Chinese (`zh-TW`).

---

## Golden rules

1. **Know source vs output** before editing. If a path is generated, change the generator / source, then rebuild.
2. **Never implement ebook features by editing `wenda2_ebook/`** — change `tool/word2ebook/`, then `python3 gen_all.py`. Same for play buttons: edit maps / injectors, not chapter HTML.
3. **`wenda/` is not ebook output** — hand-maintained 12-chapter TOC pages; regenerating the ebook does **not** update `wenda/`.
4. **`audio` is a local symlink** (`/Users/paul/tai/audio`), gitignored — never commit audio blobs here.
5. **Do not confuse site chrome with ebook assets** — root `script.js` / `style.css` ≠ `wenda2_ebook/assets/` (built from `tool/word2ebook/assets/`).
6. **Internal editors** (`/qa/`, `/audio_map/`) are editorial UIs; `robots.txt` disallows `/qa/`.

## Main data flows

### 問答錄 2 ebook (canonical “進入電子書”)

```
問答錄2/*.docx + *.pdf
        │
        ▼
tool/word2ebook/gen_all.py  (+ data/audio_map/*.json inject)
        │
        ▼
   wenda2_ebook/     ← published; do not hand-edit for features
```

Audio-map pipeline (optional but used for play buttons):

```
SRT / opus  →  tool/pdf_audio_map/   →  tool/word2ebook/data/audio_map/*.json       (PDF chapters 13–21)
            ⇘  tool/word_audio_map/  ⇒  tool/word2ebook/data/audio_map_word/word-*.json (Word chapters 01–12)
                      ▲                         │
              /audio_map/ UI (tweak)            ▼
                       inject_chapters() / inject_word_chapters() at ebook build
```

`qa/*.txt` feeds proofreading and (for 2025-11…2026-03) alignment hints; it is **not** an input to the default full rebuild.

### Homepage dual entry for 問答錄

| CTA on `index.html` | Target | Nature |
|---------------------|--------|--------|
| 查看目錄 | `wenda.html` → `wenda/chapter-*.html` | Hand TOC (12 themes) |
| 進入電子書 | `wenda2_ebook/index_trad.html` | Generated full ebook |

Do not assume these stay content-synced automatically.

### Stories

```
stories/<original>
   → tool/stories2html/extract.py  → build/<slug>.json  (gitignored)
   → build.py                      → stories/<slug>.html
   → build_index.py                → stories.html, index.html, sitemap.xml
```

Register new stories in `tool/stories2html/docs.py`. Prefer fixing extract/layout over long hand-edits of generated HTML.

### ASR / denoise (offline media; outside Pages content)

```
mp3  →  (optional) tool/audio_denoiser
     →  tool/sense_voice  →  .srt / .txt
     →  tool/pdf_audio_map / tool/qa_resplit
```

## Where to edit (quick)

| Want to change… | Edit… | Then… |
|-----------------|-------|--------|
| Ebook UI / behaviour / search / i18n | `tool/word2ebook/` | `python3 gen_all.py` (see tool `AGENTS.md`) |
| Ebook source text (Word/PDF months) | `問答錄2/` | `gen_all.py` |
| Play-button time ranges | `tool/word2ebook/data/audio_map/` (or `/audio_map/` UI / `pdf_audio_map`) | Rebuild ebook |
| Site landing / nav / about | Root HTML + `script.js` / `style.css` | Commit |
| 12-theme TOC pages | `wenda.html`, `wenda/` | Commit (no ebook rebuild) |
| Story reader text/layout | `stories2html` + originals / `docs.py` | extract → build → verify → build_index |
| QA proofreading transcripts | `qa/*.txt` (or `/qa/` editor) | Commit; ebook only if you pass `--qa` |
| Infographic / mindmap | `infographic/`, `infographic.html`, `mindmap.html` | Commit |

## Ambiguous / easy-to-misread paths

| Path | Clarification |
|------|----------------|
| `wenda/` vs `wenda2_ebook/` | Different products. `wenda/` = hand site TOC. `wenda2_ebook/` = generated ebook. |
| `問答錄2/` vs `wenda2_ebook/` | Source documents vs build output. |
| `audio_map/` vs `tool/word2ebook/data/audio_map/` | UI vs JSON source of truth. |
| `qa/` vs ebook chapters | Editorial transcripts; default `gen_all` uses PDF for Nov–Mar, not `qa/`. |
| Root `script.js` vs ebook `script.js` | Unrelated; ebook bundle is concatenated from modules under `tool/word2ebook/assets/js/modules/`. |
| `scripts/` | Empty; ignore unless something is added. |
| `tool/video_creator/` | Standalone media helper; not wired into Pages. |
| Production `/audio/` | Code expects same-origin audio; files are not in this git repo. Local preview needs the symlink. |
